# Instantly Dataset Wiki

База знаний по нашей outreach-операции в Instantly. Поверх Postgres-датасета `instantly_dataset` (1.7M писем, 167K лидов, 1881 кампаний).

## Зачем

Не делать одну и ту же аналитику дважды. Когда LLM-агент что-то выясняет (что зашло, что нет, какие темы работают, какие mailbox-ы дохнут), он **записывает сюда**. Следующий раз — берёт готовое.

[Паттерн от Карпатого](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f).

## С чего начать

- **Просто посмотреть, что есть** → [`index.md`](./index.md)
- **Спросить агента** → агент сам читает [`CLAUDE.md`](./CLAUDE.md) и идёт по структуре
- **Понять схему БД** → [`concepts/dataset-schema.md`](./concepts/dataset-schema.md)
- **Понять метрики** → [`concepts/key-metrics.md`](./concepts/key-metrics.md)
- **Лучшие практики** → [`playbook.md`](./playbook.md)
- **Хронология открытий** → [`log.md`](./log.md)

## Структура

```
wiki/
├── CLAUDE.md          ← инструкции для AI-агента (он читает первым делом)
├── README.md          ← этот файл
├── index.md           ← оглавление, AI поддерживает
├── log.md             ← append-only лог инсайтов
├── playbook.md        ← дистиллированные best practices
├── concepts/          ← определения, схема, метрики
├── campaigns/         ← глубокие разборы конкретных кампаний
├── clients/           ← сводки по клиентам
├── verticals/         ← наблюдения по отраслям
├── subjects/          ← паттерны успешных/провальных subject-line
├── mailboxes/         ← здоровье mailbox-аккаунтов
└── analyses/          ← разовые ответы на вопросы (YYYY-MM-DD-topic.md)
```

## Как обновляется

Wiki это **не автомат**. AI пишет сюда **только когда:**
1. Пользователь явно просит проанализировать (тогда AI создаёт страницу или дописывает в существующую)
2. AI замечает компаундный инсайт (что-то что поможет следующим запросам)
3. Запускается lint-проход (по запросу пользователя — `проверь wiki на устаревшее`)

Сырые данные за день обновляются через ночной cron sync ([sync.mjs на prod](../app/scripts/instantly-dataset/sync.mjs)) — wiki ничего не знает про это, она опирается на свежесть БД.
