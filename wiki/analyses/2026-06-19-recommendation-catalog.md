## Отвергнуто (нельзя сделать объективно)

- **D) «ставь паузу N дней»** — 89-92% кампаний используют одинаковые задержки, вариации нет; знак разворачивается в 3/13 сегментов. Только гипотеза для within-campaign A/B.
- **H) тренд баунса по времени** — дневная колонка `bounced` 100% NULL; колебания 4-9% = микс кампаний, не движение.
- **G) рейтинг ящиков по баунсу** — `i_status` 99% NULL на отправках, не атрибуцировать. Только слабая warmup-spam карточка.
- **«быстрый ответ → больше сделок» / любой ROI** — сделок/денег в датасете НЕТ; связь обратно-причинная (горячий лид и пишет сильнее, и отвечает быстрее).
- **«списки выгорают» как закон** — Q1-vs-Q4 конфаундит микс касаний/источник/календарь/цензуру; чистый per-touch тест дал лишь слабый спад и разошёлся в знаке.

## Сквозные правила честности

reply rate помечать «reply», не «интерес»; никаких денег/ROI (поля нет); всё tier B/C, причинность только для будущих within-campaign A/B; FDR + lag-settled окно для ночных алертов; min-n + Wilson, отказ «мало данных» вместо шумной цифры; источник/сегмент/клиент доминируют над копией (ловушка студии №1) — сравнения только within-client/within-segment с непересекающимися CI; off-platform слепые пятна (65 кампаний без ue3) исключать.
