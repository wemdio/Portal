## Обязательные гейты будущей фичи (иначе она врёт)

- Universe tag: email-derived (822 камп., 2026-03+) vs snapshot-derived (lifetime, в основном as-of 05-21) — никогда не смешивать в одном рейтинге.
- Min-n + Wilson CI: rate не показывается при n_sent<200; A/B-вердикт при ≥1000 отправок на вариант; вместо цифры — честное «недостаточно данных».
- FDR-поправка (Benjamini–Hochberg q=0.10) для ночных сканов по ~800 кампаниям — иначе ~40 ложных алертов/ночь при α=0.05.
- Возраст кампании из raw_campaigns.timestamp_created, не из min(timestamp_email) (это часто обрыв ретеншена). Сравнения только age-matched (день-30 vs день-30).
- Запрет слов «гарантированно/обязательно улучшит»; формат рекомендации: гипотеза + CI эффекта + эксперимент для проверки + дата замера в реестре.
- Рекомендации только для кампаний, которые можно менять (active=195, paused=156).

## Приоритетные фиксы датасета

1. **СРОЧНО — остановить выгорание истории:** еженедельный FULL overview-снапшот (был один раз 05-21) + восстановить ingest daily-аналитики (код уже починен, таблица пуста) + проверить ok=NULL снапшот от 05-29. История горит на 90-дневном фитиле — всё остальное может подождать месяц, это нет.
2. **Канонический слой метрик** (~день SQL): один view — DISTINCT-lead ответы, клампы дат [2025-08-01, now], force UTC, карантин сентинелей и недокументированных кодов, universe tag. Убивает сразу: 20% дубль-инфляцию, ∞-рейты, фантомный 2008, смешение источников.
3. **Бэкфилл исходов:** LLM-классификация 43,307 неразмеченных тел ответов по единой рубрике (тела хранятся с 2025-08 → ~10 мес честного lead rate) + версионирование источника метки + разобраться с квалификатором (4 строки!).
4. **Атрибуция:** домаппить клиентов (закрыто 49.6% кампаний / 81% объёма), разобрать other_unclear (481 кампания, 23.7%).
5. **Реестр рекомендаций/изменений кампаний** — без него «наш совет улучшил результат» нефальсифицируемо, а через 90 дней «до» сгорает.
6. **Гигиена:** ночной архив raw_accounts (15% ящиков уже потеряно), FBL/spam-complaint источник, докфиксы (2.12M строк; ретеншен ~90д; steps 0-indexed; TZ UTC+4).

**Вердикт:** «оценка кампании» как продукт — реальна, но только как система с правом молчать: интервалы вместо точек, уровни доказательности A/B/C, отказ при нехватке данных, и петля рекомендация→эксперимент→замер. «Советы, гарантированно улучшающие результаты, без ошибок» — невозможны статистически; обещать их нельзя ни в одном UI-тексте.
