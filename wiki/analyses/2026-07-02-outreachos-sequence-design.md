**Метод:** workflow из 4 исследователей (wiki-знания; SQL структура цепочек; SQL темы+ниши; оффер лендинга) → синтез → **адверсариал-верификатор** (свой SQL, ловля черри-пикинга/смешения источников). Всего ~77 SQL-запросов, залогировано в query_log.

**Оффер (финал после турнира, 2026-07-02):** владелец отверг 3 итерации («слабый, кринжовый, спамный, продажный»). Проведён оффер-турнир: майнинг выигравших офферов корпуса (1428 кампаний ≥1000 отправок по v_reply_outcomes) → 5 генераторов → 3 судьи (dataset-fit / получатель ×1.5 / честность) → синтез. **Победитель единогласно: routing-inbound** — каркас нашей же кампании Polza «b2b hh» (11.5 поз./1000, топ-25 корпуса, та же ЦА и тип базы): шаг 1 = чистый роутинг БЕЗ оффера, шаг 2 = «клиенты для вас» + пруф своими объёмами + give-first-деливерабл, шаг 3 = механика/цена/прозрачность.

**Оффер-архетипы корпуса (майнинг 2026-07-02, см. query_log):** выигрывают (A) «поставляем то, что вы и так закупаете» + микро-роутинг (VELAR 22.9, Moreland 21.3 поз./1000); (B) канальное «вы заработаете» — единственный живой контекст «партнёрства» (InMyRoom 9.7); (C) боль=драйвер выручки ниши (TSMedia 13.6). Ранее отвергнутые варианты: мета-хук-гиммик; анти-найм («вы ищете менеджера» — фактически неверен: парсим ЛЮБЫЕ вакансии); сухой агентский контраст без ценности.

## Что верификатор ОПРОВЕРГ (не цитировать)

1. **«Follow-up конвертят в лида 2× лучше; шаги 2–3 несут 47% лидов»** (playbook, 2026-05-30) — на полном покрытии v_reply_outcomes направление ОБРАТНОЕ (first-touch positive-share 20.4% vs 13.8% within-campaign, 568 кампаний). Плейбук аннотирован contested. 3 шага держатся на объёме, не на «качестве follow-up».
2. **Экономика длины цепочки «1→2 +1.6пп…»** — не реплицируется (completed-cut даёт пик на 2 шагах); кросс-кампанийное сравнение длины — не evidence (конфаунды).
3. **«10.35% pooled» для темы 1A** — черри-пик (Uremont, псевдо-inbound). Честные цифры: 4.43% at scale; 4.2–5.4% на своих HH-базах.

## Прогноз (консервативно)

Reply на лида за секвенцию **~2–3%** при попадании в ICP (~1.5% + 0.8% + 0.45% по шагам; ~20% из них автоответы). Interested: исторически 1.1–3.1/1000 отправок по нашим нишам → ~1.5–4/день в середине рампа 35 ящиков. Сегмент <1% reply = чинить базу/ICP/доставляемость, не копи (leads/1k утраивается при выходе из бакета <1%). Отправок на лида при 3 шагах ≈ 2.4–2.9 → ёмкость новых лидов ~480–580/день на 40/ящик (→ ~850–1000 на 70). Судить сегменты только по квал-лидам (v_reply_outcomes) на ≥200 отправок.

## Pre-flight (до первой отправки)

1. **БЛОКЕР:** проверить прод https://app.outreachos.pro/demo (по памяти /demo не задеплоен) + приём demo-lead алертов.
2. Тест-отправка: рендер {{companyName}}/{{website}} (поля лида company_name/website из пайплайна).
3. Трекинг открытий выключить в кампании; stop_on_reply on; Вт–Чт 11–16 МСК.
4. Шаг 3 обещает «первую базу по вашей ЦА соберём бесплатно» — договориться, кто и как выполняет (это ручная работа при ответе).
