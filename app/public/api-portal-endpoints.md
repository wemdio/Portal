# API портала — справочник ручек

Подробное описание каждой ручки. Обзор и объяснение «что это вообще» —
в [api-portal.md](./api-portal.md).

**База:** `https://polza-portal.ru/api/bench/v1`
**Авторизация:** заголовок `Authorization: Bearer bench_live_...`
(либо `X-Api-Key` с тем же значением)

Все ответы — JSON. Все ошибки одной формы:

```json
{ "error": { "code": "invalid_params", "message": "…", "details": null } }
```

Коды ошибок общие для всех ручек, поэтому в каждом разделе перечислены только
те, что специфичны именно для него. Полный список — в конце.

---

## GET /tools

Что доступно вашему ключу. **Начинайте отсюда:** ручка отдаёт точные параметры
каждого инструмента в машинном виде, и они не могут разойтись с реальностью —
собираются из того же кода, который проверяет ваши запросы.

Параметров нет.

**Ответ**

```json
{
  "tools": [
    {
      "id": "yandexmaps",
      "kind": "job",
      "title": "Яндекс.Карты",
      "stop_supported": false,
      "stop_reason": "Яндекс.Карты не поддерживают остановку задачи — дождитесь завершения",
      "params": {
        "type": "object",
        "properties": {
          "search_urls": { "type": "array", "items": { "type": "string", "format": "uri" } },
          "max_results": { "type": "integer", "minimum": 1, "maximum": 5000, "default": 1000 }
        },
        "required": ["search_urls"],
        "additionalProperties": false
      }
    }
  ]
}
```

| Поле | Значит |
|---|---|
| `id` | значение для параметра `tool` или `source` |
| `kind` | `job` — долгая задача, `search` — быстрый поиск |
| `stop_supported` | можно ли остановить задачу этого инструмента |
| `stop_reason` | если нельзя — почему; иначе `null` |
| `params` | JSON Schema параметров: что обязательно, границы, умолчания |

**Пример**

```bash
curl -H "Authorization: Bearer $KEY" https://polza-portal.ru/api/bench/v1/tools
```

## POST /jobs

Поставить долгую задачу.

**Тело**

| Поле | Тип | Обязательно | Что это |
|---|---|---|---|
| `tool` | строка | да | идентификатор инструмента из `/tools` |
| `params` | объект | да | параметры инструмента, см. его схему в `/tools` |

**Ответ** — задача в общей форме (одинаковой у всех инструментов):

```json
{
  "id": "9f2c1b7e-…",
  "tool": "yandexmaps",
  "status": "queued",
  "progress": { "done": 0, "total": null },
  "rows_found": 0,
  "error": null,
  "created_at": "2026-09-01T10:00:00.000Z",
  "finished_at": null
}
```

**Особые ошибки**

| Код | Когда |
|---|---|
| `invalid_params` | параметры не прошли схему; в `details` — какое поле и что не так |
| `not_found` | такого инструмента нет или он не относится к долгим задачам |
| `conflict` | у вас уже висит максимум незавершённых задач по этому инструменту |
| `quota_exceeded` | исчерпана суточная норма новых задач |

**Заметки**

- Владелец задачи берётся из ключа. Прислать чужой идентификатор в `params`
  нельзя — схемы строгие, лишние поля отвергаются.
- Неудачная попытка (`invalid_params`) суточную норму не тратит — отлаживайте
  спокойно.

**Пример**

```bash
curl -X POST https://polza-portal.ru/api/bench/v1/jobs \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"tool":"yandexmaps","params":{"search_urls":["https://yandex.ru/maps/?text=кофейни"],"max_results":200}}'
```

## GET /jobs

Ваши последние задачи по одному инструменту.

| Параметр | Обязательно | Что это |
|---|---|---|
| `tool` | да | идентификатор инструмента |
| `status` | нет | фильтр: `queued`, `running`, `done`, `failed`, `stopped` |

Отдаётся до **100** последних задач, новые сверху.

**Ответ**

```json
{ "jobs": [ { "id": "…", "tool": "…", "status": "done", … } ] }
```

Задачи других ключей и сотрудников сюда не попадают.

## GET /jobs/{id}

Состояние одной задачи.

| Параметр | Обязательно | Что это |
|---|---|---|
| `tool` | да | инструмент, которому принадлежит задача |

`tool` обязателен, потому что идентификаторы задач уникальны только внутри
своего инструмента: три инструмента вообще делят одну таблицу.

**Ответ** — та же форма, что у `POST /jobs`.

| Поле ответа | Что означает |
|---|---|
| `status` | `queued` · `running` · `done` · `failed` · `stopped` |
| `progress.done` | сколько единиц работы сделано |
| `progress.total` | сколько всего; `null`, пока объём неизвестен |
| `rows_found` | сколько строк уже собрано |
| `error` | причина падения, если `status: "failed"` |
| `finished_at` | когда завершилась; `null`, пока идёт |

**Особые ошибки**

| Код | Когда |
|---|---|
| `not_found` | задачи нет **или она принадлежит другому ключу** — не различаем намеренно |

**Заметки**

- Опрашивайте раз в 10–30 секунд. Чаще незачем: работа идёт минутами и часами,
  а каждый запрос тратит минутный лимит.
- `progress.total: null` в начале — норма, а не ноль работы.

## GET /jobs/{id}/results

Забрать результат.

| Параметр | Обязательно | Умолчание | Что это |
|---|---|---|---|
| `tool` | да | — | инструмент задачи |
| `limit` | нет | 200 | размер страницы, максимум 1000 |
| `cursor` | нет | — | курсор из предыдущего ответа |

**Ответ**

```json
{ "rows": [ … ], "cursor": "a1b2c3", "has_more": true }
```

Пока `has_more` истинно — повторяйте запрос, подставляя полученный `cursor`.
Когда страниц больше нет, `cursor` равен `null`, а `has_more` — `false`.

Смещения (`offset`) здесь нет намеренно: результаты дописываются прямо во время
выгрузки, и по номерам строк вы бы их теряли и дублировали.

**Ответ для обогащения по ИНН** — там результат файл, а не строки:

```json
{ "kind": "file", "url": "https://…", "expires_in_seconds": 900 }
```

Ссылка живёт 15 минут, ведёт ровно на файл этой задачи. Понадобится позже —
запросите ручку снова, придёт новая ссылка.

**Особые ошибки**

| Код | Когда |
|---|---|
| `not_found` | задачи нет или она чужая |
| `conflict` | результат-файл ещё не готов — дождитесь `status: "done"` |
| `quota_exceeded` | исчерпана суточная норма строк |

**Заметки**

- Отданные строки идут в суточную норму. Норма общая с `POST /search`.
- Забирать результат можно и у незавершённой задачи — придёт то, что собрано
  на этот момент.

## POST /jobs/{id}/stop

Остановить задачу.

| Параметр | Обязательно | Что это |
|---|---|---|
| `tool` | да | инструмент задачи |

Тело не нужно.

**Ответ** — задача в общей форме со `status: "stopped"`.

**Особые ошибки**

| Код | Когда |
|---|---|
| `conflict` | инструмент не поддерживает остановку — в `message` написано, какой именно |
| `conflict` | задача уже завершена, останавливать нечего |
| `not_found` | задачи нет или она чужая |

**Заметки**

- Поддержку проверяйте заранее по полю `stop_supported` в `/tools`, а не
  методом проб.
- Остановка настоящая: у поддерживающих инструментов работа действительно
  прекращается, а не просто меняется надпись.

## POST /search

Быстрый поиск по уже собранным базам. Очереди нет, ответ приходит сразу.

**Тело**

| Поле | Тип | Обязательно | Умолчание | Что это |
|---|---|---|---|---|
| `source` | строка | да | — | `company-base`, `2gis` или `our-bases` |
| `filters` | объект | нет | `{}` | фильтры источника, схема — в `/tools` |
| `limit` | число | нет | 200 | размер страницы, максимум 1000 |
| `cursor` | строка | нет | — | курсор из предыдущего ответа |

**Ответ**

```json
{ "rows": [ … ], "cursor": "…", "has_more": true }
```

**Особые ошибки**

| Код | Когда |
|---|---|
| `not_found` | такого источника нет или он относится к долгим задачам |
| `invalid_params` | фильтры не прошли схему |
| `quota_exceeded` | исчерпана суточная норма строк |

**Пример**

```bash
curl -X POST https://polza-portal.ru/api/bench/v1/search \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"source":"company-base","filters":{"country":["russia"]},"limit":200}'
```

## Параметры инструментов

Точные схемы — в `GET /tools`, там же границы и умолчания. Ниже — главное, что
стоит знать до первого запроса.

| Инструмент | Ключевые параметры |
|---|---|
| `base-constructor` | `data` — массив строк, первая строка заголовки; `selected_steps` — список шагов; `step_config` |
| `yandexmaps` | `search_urls` — ссылки на выдачу; `max_results` |
| `googlemaps` | `input_lines` — запросы; `limit_per_query`; `language`; `region`; `enrich_contacts` |
| `googlenews` | `input_lines`; `limit_per_query`; `language`; `region` |
| `hh` | `text` — поисковый запрос; `area`; `salary_from`; `date_from` / `date_to`; `fetch_employers` |
| `hh-archive` | `search_queries`; `date_from` / `date_to`; `area`; `chunk_strategy`; `max_results` |
| `ats` | `ats` — greenhouse / lever / ashby; `countries`; `posted_within_days`; `companies_limit` |
| `eng-hiring` | `sources`; `countries`; `posted_within_days`; `companies_limit`; `max_results` |
| `search` | `queries`; `search_depth` |
| `yandex-direct` | `keyword_mode` — manual / ai; `keywords` либо `audience`; `regions`; `niche` |
| `inn-enrich` | `inns` — список ИНН строками |
| `company-base` *(поиск)* | `country`, `industry`, `size`, `name` |
| `2gis` *(поиск)* | `cities`, `rubric_groups`, `name`, `has_phone`, `has_email`, `has_website` |
| `our-bases` *(поиск)* | `region_codes`, `activity_types`, `okved_codes`, `legal_forms`, `has_phone`, `has_email` |

**Обязательные сочетания, которые легко пропустить**

- `base-constructor` с шагом `ta_scoring` требует непустой `step_config.brief`,
  с шагом `personalization` — непустой `step_config.prompt`. Без них запрос
  отвергается: пустой бриф молча отбросил бы все строки ниже порога.
- `yandex-direct` при `keyword_mode: "manual"` требует непустой `keywords`,
  при `"ai"` — непустой `audience`.

## Коды ошибок

| Код | HTTP | Что произошло | Что делать |
|---|---|---|---|
| `unauthorized` | 401 | ключа нет, он неверный или отозван | проверить заголовок, запросить новый ключ |
| `tool_not_allowed` | 403 | инструмент не открыт вашему ключу | попросить админа открыть |
| `invalid_params` | 400 | параметры не прошли проверку | смотреть `details` — там поле и причина |
| `rate_limited` | 429 | слишком часто | подождать столько, сколько в `Retry-After` |
| `quota_exceeded` | 429 | кончилась суточная норма | ждать полуночи по Москве либо просить поднять лимит |
| `not_found` | 404 | нет такой задачи или инструмента | проверить `tool` и идентификатор |
| `conflict` | 409 | так сейчас нельзя | читать `message`, там причина |
| `server_error` | 500 | сломалось у нас | повторить через несколько секунд |

Повторять после отказа можно, но с паузой. Цикл без пауз только усугубит:
`429` вернётся снова, а норма к тому времени не восстановится.

## Лимиты

У ключа четыре потолка, их задаёт админ при выдаче:

| Лимит | Что считает |
|---|---|
| запросов в минуту | все обращения к API |
| новых задач в сутки | только успешные постановки |
| строк в сутки | сумма строк из `/results` и `/search` |
| задач одновременно | незавершённые задачи по одному инструменту |

Суточные нормы обнуляются в полночь по Москве. При превышении в `details`
приходит `resets_at` — когда счётчик обнулится.
