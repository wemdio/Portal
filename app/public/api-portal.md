# API портала

Обычно инструментами студии пользуются руками: заходишь в портал, выбираешь
парсер, нажимаешь кнопку, ждёшь, скачиваешь файл.

API — то же самое, но из программы. Скрипт отправляет запрос, портал делает ту
же работу теми же инструментами, скрипт забирает результат. Ничего отдельного
или параллельного не создаётся: это те же задачи, что и из интерфейса.

---

## Как это устроено

Инструменты делятся на два вида.

**Долгие** — парсеры и конструктор баз. Работают минутами и часами, поэтому
работают так: скрипт **ставит задачу**, изредка **спрашивает, как дела**, потом
**забирает результат**. Ровно как человек: запустил, ушёл, вернулся.

**Быстрые** — поиск по базам, которые у нас уже собраны. Отвечают сразу, ждать
нечего.

## Ключ

Ключ выдаёт админ портала. Он определяет две вещи: **какие инструменты
открыты** и **сколько можно** — запросов в минуту, задач в сутки, строк в сутки.

Ключ показывается один раз. Потеряли — попросите новый, восстановить старый
нельзя. Отзыв мгновенный: как только админ нажал «Отозвать», ключ перестаёт
работать.

## Что можно запускать

Долгие задачи:

| Инструмент | Что делает | Можно остановить |
|---|---|---|
| Конструктор баз | обогащает загруженную базу выбранными шагами | да |
| Яндекс.Карты | собирает организации из выдачи | нет |
| Google Maps | то же по Google | да |
| Google News | собирает новости | да |
| HH | вакансии и работодатели | нет |
| HH архив | то же за прошлый период | да |
| ATS | компании по системам найма | нет |
| ENG hiring | вакансии на западных площадках | нет |
| Поисковый парсер | сбор по поисковой выдаче | нет |
| Яндекс.Директ | рекламодатели по ключевым словам | да |
| Обогащение по ИНН | дополняет компании по реквизитам | нет |

Быстрый поиск: **наша база компаний**, **2GIS**, **наша база баз**.

Остановка есть не у всех — там, где её нет, задачу придётся дождаться. Это не
ограничение доступа: у этих парсеров кнопки «стоп» нет и в самом портале.

## Чего API не делает

Это решения, а не недоделки — чтобы не искали.

- **Не удаляет.** Ни задачи, ни данные удалить нельзя вообще никак.
- **Не показывает чужое.** Задачи других ключей и сотрудников для вас не
  существуют.
- **Не даёт финансовые данные** — приходы и кошелёк студии в API не входят.
- **Не пускает к Telegram-аккаунтам** — они живые, их банят, и рисковать ими
  ради парсинга чатов не стали.

## Сколько можно

У ключа четыре потолка, их задаёт админ при выдаче:

- запросов в минуту;
- новых задач в сутки;
- строк результата в сутки;
- задач одновременно.

Сбор данных стоит денег и расходует общий пул прокси, поэтому потолки есть у
всех. Превысили — придёт вежливый отказ с указанием, когда можно снова.
Суточные нормы обнуляются в полночь по Москве.

# Дальше — для того, кто пишет код

## Авторизация

```
Authorization: Bearer bench_live_...
```

Базовый путь: `/api/bench/v1`. Если заголовок `Authorization` занят — подойдёт
`X-Api-Key`.

## Ручки

| Что делаем | Запрос |
|---|---|
| Узнать, что доступно | `GET /tools` |
| Поставить задачу | `POST /jobs` |
| Узнать статус | `GET /jobs/{id}?tool=…` |
| Забрать результат | `GET /jobs/{id}/results?tool=…` |
| Остановить | `POST /jobs/{id}/stop?tool=…` |
| Свои задачи | `GET /jobs?tool=…` |
| Быстрый поиск | `POST /search` |

Идентификаторы для поля `tool`: `base-constructor` · `yandexmaps` ·
`googlemaps` · `googlenews` · `hh` · `hh-archive` · `ats` · `eng-hiring` ·
`search` · `yandex-direct` · `inn-enrich`.

Источники для `POST /search`: `company-base` · `2gis` · `our-bases`.

`tool` обязателен везде, где он есть: идентификаторы задач уникальны только
внутри своего инструмента.

**`GET /tools` — главное здесь.** Он перечисляет инструменты, открытые вашему
ключу, и для каждого отдаёт точный список параметров в машинном виде. Этот
список собирается из того же кода, который проверяет запросы, поэтому устареть
не может. Все параметры смотрите там, а не в этом файле.

## Статусы задачи

`queued` — в очереди · `running` — выполняется · `done` — готово ·
`failed` — упала, причина в поле `error` · `stopped` — остановлена.

Пока объём работы неизвестен, `progress.total` равен `null` — это нормально в
начале, не считайте его нулём.

## Результаты

Отдаются страницами. В ответе есть `cursor` и `has_more`: пока `has_more`
истинно, повторяйте запрос с полученным курсором.

Курсор, а не номер страницы — потому что результаты дописываются прямо во время
выгрузки, и по номерам строки терялись бы и дублировались.

У обогащения по ИНН результат — файл, поэтому вместо строк придёт ссылка на
скачивание, живущая 15 минут.

## Пример

```python
import time, requests

S = requests.Session()
S.headers["Authorization"] = "Bearer bench_live_..."
API = "https://<хост-портала>/api/bench/v1"

# 1. поставить задачу
job = S.post(f"{API}/jobs", json={
    "tool": "yandexmaps",
    "params": {"search_urls": ["https://yandex.ru/maps/?text=кофейни"], "max_results": 200},
}).json()

# 2. подождать (раз в 15 секунд — чаще незачем)
while job["status"] in ("queued", "running"):
    time.sleep(15)
    job = S.get(f"{API}/jobs/{job['id']}", params={"tool": "yandexmaps"}).json()

# 3. забрать результат страницами
rows, cursor = [], None
while True:
    page = S.get(f"{API}/jobs/{job['id']}/results",
                 params={"tool": "yandexmaps", "limit": 500, "cursor": cursor}).json()
    rows += page["rows"]
    if not page["has_more"]:
        break
    cursor = page["cursor"]

print(len(rows))
```

Быстрый поиск проще — ответ приходит сразу:

```python
S.post(f"{API}/search", json={
    "source": "company-base",
    "filters": {"country": ["russia"]},
    "limit": 200,
}).json()
```

## Ошибки

Форма всегда одна: `{"error": {"code": "...", "message": "...", "details": ...}}`.

| Код | Что произошло |
|---|---|
| `unauthorized` | ключа нет, он неверный или отозван |
| `tool_not_allowed` | инструмент не открыт вашему ключу |
| `invalid_params` | параметры не прошли проверку, подробности в `details` |
| `rate_limited` | слишком часто — подождите столько, сколько скажет `Retry-After` |
| `quota_exceeded` | кончилась суточная норма |
| `not_found` | такой задачи нет **или она чужая** — мы намеренно не различаем |
| `conflict` | так сейчас нельзя: остановить завершённую, забрать неготовое |
| `server_error` | сломалось у нас |

Повторять запрос после отказа можно, но с паузой. На `429` — дождитесь времени
из `Retry-After`, на `500` — нескольких секунд. Цикл без пауз только усугубит.

## Для тех, кто дорабатывает API

Зачем всё устроено именно так и что намеренно не вошло —
[`docs/superpowers/specs/2026-08-30-bench-api-design.md`](../../docs/superpowers/specs/2026-08-30-bench-api-design.md).

Добавить инструмент — написать адаптер в `app/src/lib/bench/tools/` и внести в
реестр `app/src/lib/bench/registry.ts`. Роуты про конкретные инструменты ничего
не знают, менять их не нужно; в `GET /tools` новый появится сам.
