# Источники сбора B2B-баз (канон агентства)

Это все источники, которыми мы собираем базы под клиента. Список — из «генератора
гипотез» (`LEAD_SOURCES` в портале), то есть это проверенные способы, а не выдумка.
Под каждым: что вытащить, когда применять, пример, как запустить.

> Правило: подбирай источник **под боль/сигнал ЦА**, а не «соберём всех в IT».
> Не предлагай чужие сервисы (LinkedIn Sales Navigator, Apollo и т.п.) — их у нас нет.

---

## 1. HH (HeadHunter, hh.ru)
Парсим публичные вакансии работодателей.
- **Что вытащить:** список компаний по фильтру (ключевое слово в названии вакансии, регион, отрасль), сигналы найма (рост команды, открытие направлений, нехватка роли).
- **Когда:** ЦА — компании, которые активно нанимают (значит есть бюджет/рост/потребность в смежном). Хорошо комбинируется с обогащением контактами через сайт.
- **Пример:** «Крупные SaaS из МСК/СПб, нанимающие B2B-маркетологов или sales за 30 дней».
- **Запуск:** конструктор баз / HH-парсер по **ссылке поиска вакансий** (не раздел «Компании»).
- ⚠️ HH **не отдаёт ССЧ/выручку** — не используй их как фильтр или следующий шаг для HH-гипотез.

## 2. Реестровые базы: Руспрофайл, Селеком, Сбис
Открытые реестры юрлиц с глубокой фильтрацией.
- **Что вытащить:** ОКВЭД (осн.+доп.), выручка по отчётности (диапазоны), ССЧ, регион, форма (ООО/ИП/АО), статус (действующая/ликвидирована), дата регистрации, лицензии, госконтракты.
- **Когда:** классический B2B с чёткой ICP и понятными отраслевыми/финансовыми критериями.
- **Пример:** «ООО, ОКВЭД 47.78, выручка 50–500 млн ₽, ССЧ 10–100, ЦФО».
- **Запуск:** выгрузка из реестра → конструктор баз.

## 3. Поисковая выдача (Google + Яндекс)
Язык поисковых операторов (`site:`, `intitle:`, `inurl:`, "контакты", "официальный сайт"…).
- **Что вытащить:** нишевые компании и страницы с контактами.
- **Когда:** небольшие тематические базы, нишевые игроки без заметного ОКВЭД, но с конкретным продуктом/услугой на сайте.
- **Пример:** `"производитель тротуарной плитки" Москва "контакты" -site:hh.ru`.
- **Запуск:** парсер поисковой выдачи в Портале.

## 4. Яндекс.Карты и Google Maps
Карточки организаций: локация, сайт, телефон, рубрика, отзывы.
- **Когда:** локальный B2B (HoReCa, ритейл, услуги в городах), офлайн-точки, медицина/красота/автосервисы.
- **Пример:** «Автосервисы Самары/Тольятти с рейтингом <4.0 и >20 отзывов» — низкий рейтинг = повод писать про репутацию/SERM.
- **Запуск:** парсер карт в Портале.

## 5. Каталоги/рейтинги агентств (Рейтинг Рунета и др.) — *team-only*
Открытые каталоги digital/IT/маркетинг-агентств.
- **Что вытащить:** название + сайт сразу из листинга (Рейтинг Рунета — разделы веб-разработка, SEO, SMM, дизайн, контекст…). Чисто, без захода в карточки.
- **Когда:** ЦА — сами агентства/студии/подрядчики, или нужен чистый список digital-игроков (по ОКВЭД этот сегмент собирается «грязно»).
- **Пример:** «Агентства из разделов SMM и контекст по МСК/СПб — под white-label лидген».
- Похожие (но сайты в карточках/через JS): CMS Magazine, Tagline, Sostav, AdIndex.

## 6. Crypto Payments — *team-only* (`/parsers/crypto-payments`)
По домену определяет крипто-эквайринг (NowPayments, CoinPayments, BTCPay, Cryptomus…).
- **Когда:** клиент продаёт крипто-эквайринг, on/off-ramp, AML/KYC, инфраструктуру для крипто-бизнеса. Запускается **поверх готовой базы доменов**.

## 7. Сигналы с сайтов — *team-only* (`/tools/databases`, кнопка «Сигналы»)
Сканер техстека по базе доменов.
- **Что вытащить:** рекламные пиксели (Директ, VK, myTarget, Google Ads), CRM (amo, Битрикс24, RetailCRM, HubSpot), чаты (JivoSite, Carrot Quest), call-tracking (Calltouch, CoMagic), онлайн-оплату (ЮKassa, CloudPayments, Tinkoff, Робокасса), email (Unisender, Mindbox), CMS, ссылки на маркетплейсы. → «стек» компании и комбинации («тратит на рекламу, но нет CRM»).
- **Когда:** оффер завязан на технологии или дыре в стеке (внедрение CRM, аналитика, смена эквайринга, переезд с маркетплейсов на D2C). Запускается **поверх базы доменов**.

## 8. export-base.ru — каталог готовых баз (платно)
Готовые базы по тематикам — часто дешевле/быстрее, чем парсить с нуля.
- **Категории:** ОКВЭД, отраслевые рубрики, типы компаний (с ЛПР, с автопарком, по системе налогообложения), базы сайтов по нишам, продавцы WB/OZON/ЯМ, участники выставок, должники по налогам, госзакупки 44/223-ФЗ.
- **Когда:** тематика клиента **точно** совпадает с готовой категорией. НЕ берём «для добивки».
- **Каталог:** https://export-base.ru/catalog_baz (актуальный снимок ~350 баз — в портале у генератора гипотез).

## Шпаргалка: сигнал ЦА → источник
| Наблюдаемый признак / сигнал ЦА | Источник |
|---|---|
| Активный наём роли / рост команды / новое направление | **HH** (вакансии) |
| Чёткий ОКВЭД, выручка, ССЧ, форма, возраст, лицензии, госконтракты | **Реестры** (Руспрофайл/Селеком/Сбис) |
| Нишевый продукт/услуга без явного ОКВЭД, но с сайтом | **Поисковая выдача** (Google+Яндекс) |
| Локальный/офлайн-бизнес, рубрика, рейтинг и отзывы (репутация) | **Карты** (Яндекс/Google) |
| Конкретный техстек (CMS, CRM, пиксели, эквайринг, чаты) или дыра в стеке | **Сигналы** с сайтов |
| Крипто-эквайринг на сайте | **Crypto Payments** |
| digital/IT/маркетинг-агентства, веб-студии, подрядчики | **Каталоги агентств** (Рейтинг Рунета) |
| Тематика ЦА ТОЧНО совпала с готовой категорией | **export-base.ru** (только при точном совпадении) |

> *team-only* = источники для специалиста (не отдаются клиенту как самостоятельный сценарий):
> Каталоги агентств, Crypto Payments, Сигналы.
