# Документация Bench API переехала

Живёт в [`app/public/api-portal.md`](../app/public/api-portal.md).

Причина переезда: сборка копирует в образ только `app/`, а `docs` вдобавок
исключён в `.dockerignore` — файл отсюда физически не попадал на прод, и
скачать его из портала было нельзя. В `app/public/` он едет вместе с
приложением, поэтому в админке всегда отдаётся ровно та версия, что в этой
ветке.

Держать копию здесь не стали намеренно: две копии одного документа разъезжаются
за пару правок, и потом непонятно, какая настоящая.

Дизайн и принятые решения по-прежнему тут:
[`superpowers/specs/2026-08-30-bench-api-design.md`](./superpowers/specs/2026-08-30-bench-api-design.md).
