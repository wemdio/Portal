# Кейсы для писем и диалогов русского автоаутрича

Подготовлено 29.10.2026 по запросу владельца. Короткий кейс вставляется в третье
письмо цепочки. ИИ-собеседник получает кейсы только предложенного продукта и
может привести один подходящий пример в 1–2 предложениях. Исторические
результаты не становятся обещанием такого же результата новому клиенту.

Данные подготовлены миграцией `20261029_0030_ru_product_cases.sql`. Документ не
подтверждает применение миграции или выкладку кода. Уже поставленные в отправку
письма этой правкой не переписываются.

## Автоаутрич

В предоставленном `Polza_Auto_Outreach_RU_v5.pdf`, стр. 11, уже есть отдельный
обезличенный кейс: автоматизированные кампании SaaS-сервиса для маркетинга дали
99 новых лидов за июль–сентябрь 2026, при 24 280 загруженных контактах.
Короткая формулировка: «Для SaaS-сервиса в сфере маркетинга автоматизированные
кампании дали 99 новых лидов за 3 месяца. Название клиента скрыто по NDA».

Этот кейс доступен только автоаутричу. Название клиента не угадывается и не
раскрывается. Law Russia на стр. 10 иллюстрирует механику сигнала, но не содержит
числового результата — как результативный кейс в библиотеку не добавлен.
