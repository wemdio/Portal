## 1. О платформе

**Portal** — внутренняя операционная платформа для управления проектами, продажами и аутрич-процессами. Объединяет в одном месте проектное управление, инструменты для лидогенерации, парсинга, AI-обзвона, email- и Telegram-аутрича, а также аналитику и автоматизацию рутинных задач.

**Кому предназначен:** менеджеры, технические специалисты, руководители, продажники, маркетологи.

**Ключевые категории функционала:**
- Проектное управление и трекинг задач
- Инструменты лидогенерации и парсинга
- Каналы аутрича (email, Telegram, голосовой AI)
- Обогащение и валидация данных
- Аналитика и отчётность
- Внутренние процессы (регламенты, оплаты, финансы)

## 2. Управление проектами

**Путь:** `/` (главная), `/projects/new`, `/projects/[id]`

Центральный модуль платформы — управление клиентскими проектами.

### Возможности:
- **Создание проектов** — карточка с информацией о клиенте, контактах, бюджете, марже
- **Статусы проектов:** В работе, Тест, На паузе, Подготовка, Завершён
- **Три режима отображения:** карточки, таблица, канбан
- **Фильтрация и поиск** по статусу, менеджеру, специалисту, клиенту
- **Назначение ответственных** — менеджер и специалист на каждый проект
- **KPI-трекинг** — план/факт по ключевым метрикам
- **Дедлайны** — дата контракта, оплаты, запуска, дедлайн
- **Комментарии** — текстовые заметки от участников
- **Обязательства по контактам** — план/факт по количеству контактов
- **Информация о проекте** — регион, источник лида, формат работы, тип проекта
- **Ссылки** — на контракт, материалы, передачу
- **Привязка к задачам** — задачи привязаны к проектам
- **CSV-импорт** — массовая загрузка проектов

## 3. Задачи и канбан-доска

**Путь:** `/tasks`, `/board`

Система управления задачами с drag-and-drop канбан-доской.

### Возможности:
- **Создание задач** с заголовком, описанием, результатом, изображением
- **Канбан-доска** — перетаскивание задач между столбцами (drag-and-drop)
- **Несколько досок** — создание именованных досок с произвольными столбцами
- **Статусы** — настраиваемые через столбцы доски
- **Привязка к проектам** — задача может быть связана с проектом (или быть независимой)
- **Назначение специалиста** на каждую задачу
- **Загрузка изображений** для задач (через S3)

## 7. Instantly — Email-аутрич

**Путь:** `/instantly` и подразделы

Полная интеграция с платформой Instantly для управления холодными email-рассылками.

### Кампании (`/instantly/campaigns`):
- **Список кампаний** с метриками (отправлено, открыто, ответы)
- **Создание кампании** — настройка шагов, расписания, параметров
- **Управление** — активация, пауза, детали кампании
- **Аналитика кампаний** — графики, воронки, конверсии

### Email-аккаунты (`/instantly/accounts`):
- Управление email-аккаунтами для рассылки
- Прогрев (warmup) аккаунтов
- Мониторинг состояния

### Лиды (`/instantly/leads`, `/instantly/lead-lists`):
- Управление списками лидов
- Импорт лидов (CSV)
- CRUD по отдельным лидам
- Lead labels — метки лидов

### Дополнительно:
- **Теги** (`/instantly/tags`) — организация кампаний и лидов
- **Вебхуки** (`/instantly/webhooks`) — автоматизация событий
- **Шаблоны писем** (`/instantly/email-templates`) — переиспользуемые шаблоны
- **Подпоследовательности** (`/instantly/subsequences`) — дополнительные цепочки
- **Блок-лист** (`/instantly/block-list`) — запрет отправки на определённые адреса
- **Импорт лидов** из базы данных напрямую в Instantly с привязкой к проекту

## 8. TG Аутрич — Telegram-рассылки

Инструмент массового Telegram-аутрича с AI-ответами.

### Кампании:

- **Мониторинг статуса** в реальном времени

- **Логи** — подробный лог каждого действия

- Загрузка session-файлов

### Прокси:
- Управление HTTP/SOCKS прокси

- Просмотр всех диалогов кампании

- Ручная отправка сообщений
- Экспорт диалогов
- Статусы: новый, в работе, квалифицирован, отклонён

### AI-функции:

- Квалификация лидов через AI

### Теги:
- Управление тегами для организации аккаунтов и кампаний

## 9. Парсеры

**Путь:** `/parsers`

Три парсера для сбора данных о компаниях и вакансиях.

### 9.1. Парсер HH.ru
- **Парсинг вакансий** с HeadHunter по заданным параметрам
- Информация о компаниях: название, сайт, описание, индустрии
- Данные о зарплатах, регионах, дате публикации
- Фоновый воркер с прогрессом выполнения
- Экспорт результатов

### 9.2. Парсер поиска (Google/Serper)
- **Поисковый парсинг** — массовый поиск по запросам через Google (Serper API)
- Генерация поисковых запросов (AI)
- Результаты: заголовок, ссылка, сниппет, компания, email
- Скрапинг сайтов через Playwright
- Обогащение: извлечение email, описания компании
- Статистика по каждому запросу
- Прокси для обхода лимитов

### 9.3. Парсер Яндекс Карт
- **Парсинг организаций** с Яндекс Карт по заданным запросам
- Данные: название, адрес, рейтинг, отзывы, сайт, email, телефон, соцсети (Telegram, VK, Instagram, WhatsApp)
- Категории, часы работы
- Отдельный Python-сервис (FastAPI/uvicorn)
- Двухэтапный процесс: сбор ссылок → парсинг организаций
- Фоновый воркер с прогрессом

## 12. Проверка баз (Database Review)

**Путь:** `/tools/databases/review`, `/review/base/[token]`

Система проверки качества лид-баз с workflow-процессом.

### Процесс:
1. **Специалист** собирает базу и отправляет на проверку (submit)
2. **Проверяющий** получает заявку, просматривает данные
3. **Разметка строк** — цветовые маркеры (зелёный, жёлтый, красный) и комментарии к отдельным строкам
4. **Решение** — одобрить или отправить на доработку с комментарием
5. **Публикация в Telegram** — отправка результатов клиенту через Telegram-бота
6. **Гостевой доступ** — клиент получает ссылку с токеном для просмотра базы и оставления комментариев (без регистрации)

### Статусы:
- На проверке → Одобрено / На доработке

## 13. AI Caller — Голосовой AI-обзвон

**Путь:** `/tools/ai-caller` (v1), `/tools/ai-caller-v2` (v2)

Инструмент автоматического обзвона с использованием голосового AI.

### Версия 1 — Vapi:
- **AI-ассистенты** — создание и настройка голосовых ассистентов
- **Кампании обзвона** — загрузка контактов, запуск массового обзвона
- **Тестовые звонки** — проверка ассистента перед запуском
- **История звонков** — запись, длительность, статус
- **Аналитика** — статистика по звонкам, конверсии
- **Записи разговоров** — прослушивание и отправка в Telegram

### Версия 2 — ElevenLabs:
- Аналогичный функционал на базе ElevenLabs Conversational AI
- Более продвинутый голосовой синтез

### Общее:
- **Парсинг брифа** — AI анализирует бриф клиента и генерирует настройки ассистента
- **Telegram-интеграция** — уведомления о звонках, отправка записей
- **Телефонные номера** — управление номерами для обзвона

## 14. Done For You Base (DFYB)

**Путь:** `/tools/done-for-you`

AI-автоматизация сбора лид-базы «под ключ».

### Процесс:
1. **Загрузка брифа** — текст или PDF с описанием целевой аудитории
2. **AI-планирование** — система генерирует план сбора данных
3. **Автоматический сбор** — пошаговая автоматизация (парсинг, обогащение, скоринг)
4. **Отслеживание прогресса** — визуализация текущего шага и процента выполнения
5. **Результат** — готовая база с персонализацией

### Этапы:
- Планирование → Парсинг → Обогащение → Скоринг → Персонализация → Готово

## 15. Email Sequence — Генератор цепочек писем

**Путь:** `/tools/email-sequence`

AI-генерация цепочек холодных email-писем.

### Процесс:
1. **Загрузка брифа** — описание продукта, ЦА, УТП
2. **Сегментация** — AI разбивает аудиторию на сегменты
3. **Исследование сегмента** — анализ болей, задач, решений
4. **Генерация цепочки** — AI создаёт последовательность писем для каждого сегмента

### Результат:
- Несколько сегментов с описанием
- Цепочки из 3-5 писем для каждого сегмента
- Персонализированный контент на основе болей и решений

Portal работает также как Telegram Mini App (TMA).

### Возможности:

- Авторизация через Telegram initData
- Привязка Telegram-аккаунта к профилю в Portal
- Верификация пользователя через Telegram-бота

## 24. Роли и доступ

### Роли пользователей:

| Роль | Описание |
|------|----------|
| **admin** | Полный доступ, управление пользователями и системой |
| **director** | Руководитель — доступ к финансам, аналитике, согласованиям |
| **lead** | Лид — управление командой и проектами |
| **manager** | Менеджер — работа с проектами и клиентами |
| **technician** | Технарь — работа с инструментами и парсерами |
| **sales** | Продажник — работа с лидами и аутричем |
| **marketer** | Маркетолог — аналитика, контент |

### Управление доступом:
- Видимость инструментов настраивается индивидуально для каждого пользователя
- Инструменты скрываются/показываются через `user_tool_visibility`
- Навигация адаптируется под доступные инструменты
- RLS (Row Level Security) в Supabase для разграничения данных
