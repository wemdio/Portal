# ENG: неизвестная цена запроса к модели больше не останавливает базу

22 октября 2026. Ветка назначения `Sergey`, поверх `6130636b5` (то же для
поиска). Пользователь: «так же почини запросы к моделям: неизвестную цену
списывать по резерву и продолжать сбор. Только ENG, RU и VE2 не трогай, деплой
сделаю сам». Миграций нет, записей в прод нет.

## Что было

Неизвестная цена запроса к модели (таймаут, обрыв, ошибка HTTP, ответ без
`usage.cost`, отмена задачи посреди запроса — например, при деплое)
останавливала базу в трёх местах:

1. `engBaseBudget.ts`, `settleHeEngRequestyCall`: запрос записывался в бюджет
   базы с неизвестной ценой → `hold_reason='unknown_cost'` и ошибка
   `charge_unknown` → все следующие платные действия базы отказывали.
2. `engCompanyQualification.ts`, проверка компаний: ответ без цены или сбой
   модели ставил `holdReason='model_cost_unknown'`, все оставшиеся компании
   получали «не проверена», а сбор заканчивался с `stop_reason=error`.
3. Там же, после перезапуска с запросом «в полёте»: то же самое — стоп и все
   оставшиеся компании «не проверены».

## Что сделано

- **Бюджет базы.** Неизвестная цена записывается по полному резерву. Резерв
  уже считает всё тело запроса и весь потолок ответа по самым дорогим ставкам
  каталога с двойным запасом, так что расход не занижается. Остановка
  осталась только для случая, когда цену не удалось сохранить в базу данных.
- **Проверка компаний.**
  - Ответ без цены: резерв остаётся списанным, проверка идёт дальше, блокировки нет.
  - Модель не ответила: резерв остаётся списанным, компании этого запроса
    получают ещё одну попытку позже (всего три, общий счётчик попыток
    компании), проверка переходит к следующей компании. После трёх попыток
    компания «не проверена» (`model_provider_unavailable`).
  - Три сбоя подряд или ошибка оплаты/ключа (`billing`, `configuration`) —
    пауза этого прохода на минуту, без остановки базы; компании ждут.
  - Перезапуск или отмена с запросом «в полёте»: это одна неудачная попытка
    для его компаний, остальные проверяются дальше.
- `llm.ts`: исправлен только комментарий про ENG (поведение RU не меняется —
  у RU нет бюджетной области ENG, и эти функции для него ничего не делают).

## Что по-прежнему останавливает базу

- Жёсткое убийство процесса ровно во время запроса: в бюджете базы остаётся
  неоплаченная резервация, и следующий запуск отказывает (`pending_spend`).
  Обычный деплой останавливает воркер мягко — отмена проходит по пути выше.
- Сбой базы данных при записи цены.
- Старые блокировки (`unknown_cost`, `model_cost_unknown`), уже записанные в
  прод, новый код не снимает.

## Цена

Неотвеченные запросы теперь стоят резерв. В сборе HST Insurance carriers
резерв классификатора (DeepSeek v4 flash) был $0,0014–0,0029 за запрос,
проверяющего (gpt-5-mini) — $0,013–0,014. В проверке компаний пауза после трёх
сбоев подряд ограничивает расход при отказе сервиса моделей тремя резервами в
минуту на базу; общий потолок — те же $5.

## Проверки

- TypeScript core, ESLint изменённых файлов, полный Jest, `npm run
  build:workers`. Новых `*.test.ts` нет.
- 12 офлайн-случаев на настоящих `runHeEngCompanyQualification`, `callLLMText`
  и клиенте бюджета базы; бюджетные вызовы — копия правил миграции в памяти,
  Requesty — поддельный. Обрывы (пауза после трёх, у трёх компаний по
  попытке, никто не выброшен), ещё два прохода (после трёх попыток компания «не
  проверена», остальные идут дальше), ошибка 402 (пауза после одного запроса),
  ответ без цены (все компании обработаны), отмена посреди запроса и
  продолжение после неё. Во всех случаях блокировки нет, все запросы записаны
  по резерву.

## Выпуск

Миграций и переменных окружения нет. Выкатывается вместе с остальными
коммитами ENG из `Sergey`.
