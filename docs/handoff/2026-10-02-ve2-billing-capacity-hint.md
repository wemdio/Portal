# VE2: предварительная проверка тарифа не должна запрещать дозаливку

## Подтверждённая причина

02.10.2026 пользователь повторно нажал «Дозалить контакты проекта» у StaffLine и получил сообщение о заполненном Instantly, хотя видел свободное место в его интерфейсе.

Read-only проверка около 07:01 UTC: API main workspace отдаёт `total_lead_limit=300000`, `current_lead_count=328137`. В том же ответе `subscriptions.outreach.addons_qty=22`, а `addons.outreach.existing_quantity=11`. Фактический лимит в UI не подтверждён; самостоятельно пересчитывать его по дополнениям нельзя.

Попытки VE2 30.09 и 02.10 имеют `INSTANTLY_CONTACT_CAPACITY`, 360 released, 0 accepted/uncertain. Но журнал `client_campaign_append_batches` содержит только успешную загрузку 50 контактов от 28.09. Новые запросы импорта не отправлялись: Portal остановился на billing preflight. Предыдущее описание «Instantly отказал на загрузку» было неточным — сохранённый код ошибки объединял локальную проверку и реальный отказ импорта.

## Изменение

Только для `pauseOnWorkspaceCapacity` billing определяет размер первой партии. Если там ноль, обычный запрос импорта получает один контакт из уже согласованной дневной партии, с прежним журналом и проверкой владения попыткой. Тестовых получателей нет.

Дальнейший размер партии берётся из `remaining_in_plan` ответа импорта. Если счётчика нет, старый billing hint не превращается в расчётный ноль и постоянную паузу. Явный отказ импорта из-за хранения или `remaining_in_plan=0` сохраняет прежнюю паузу. HTTP 429, транспортные ошибки и обычный HTTP 402 не считаются доказательством нехватки места.

Сохранены: общий дневной резерв, идентичность принятых контактов, неизвестные результаты, блок-лист, запрет дублей и Start/Pause в Instantly. Другие вызывающие функции без `pauseOnWorkspaceCapacity` сохраняют своё поведение. SQL и миграций нет.

## Проверка и выкладка

Перед изменением получен актуальный `test` (`33aa783f6`) через fast-forward. В существующем тестовом файле обновлены сценарии нулевого/устаревшего billing hint, подтверждённого заполнения и нескольких партий. Новых `it()` или тестовых файлов нет.

Ускоренный branch-tests: 44 suites, 431 passed / 2 skipped, 16.7 с. ESLint, TypeScript strict, сборка VE2 worker и `git diff --check` прошли.

Production только читали; платные проверки, импорты и изменения кампании не запускались. После штатного деплоя VE2 worker пользователь должен повторно нажать «Дозалить контакты проекта», поскольку существующая пауза сама не снимается. Успех живого импорта ещё не проверен; только он подтвердит фактическую доступность места.
