# VE2: редактирование общей цели проекта

Запрос: дать специалисту заметное редактирование общей цели всех запущенных гипотез. Пользователь разрешил дополнить существующие тесты. Реализация подготовлена поверх `origin/test` (`bd05d7a2b`); направление передачи — `Sergey` по прежнему явному поручению пользователя. Production не меняли.

## Интерфейс и поведение

На шаге **«Результаты»**, перед настройкой темпа, показан блок **«Общая цель проекта»** с текущим числом и кнопкой **«Изменить цель»**. Внутри — точное новое число, минимально допустимая цель, предварительный дневной план, сохранение/отмена и результат операции. Строка на шаге запуска направляет сюда вместо сообщения о неизменяемой цели.

Это одна цель VE2-проекта, без умножения на количество гипотез. Как и в текущем планировщике, выполнение — первые отправки: при наличии периода используются его факты, без периода — кампании данного VE2-проекта; отдельные ручные кампании не включаются. Дневной план — прогноз спроса с ограничением сохранённой мощности, а не обещание загрузки или отправки.

## Защита действующего запуска

Миграция `20261007_0060_ve_edit_contact_target.sql` добавляет версию цели, журнал изменений и атомарный RPC. Новый API принимает только число и ожидаемые прежнюю цель/версию; автора и факты отправок определяет сервер.

- Одновременные сохранения ограждены сравнением версии/значения и блокировками запуска/дозагрузки. Занятые строки дают понятную ошибку повтора, а не ожидание взаимной блокировки.
- Минимум учитывает выполненное, загруженное, неопределённые попытки и текущие резервы. Контакты не удаляются и не загружаются повторно.
- Сегодняшние квоты и резервы не пересоздаются. Новая цель действует на последующие планы и добор; существующее ограничение общего остатка остаётся в SQL дозагрузки.
- Число цели меняется также в согласованных настройках автодобора и совпадающих незавершённых/ошибочных порциях. Аудитории, письма, результаты проверок, паузы, ошибки, завершённые порции и устаревшие несовпадающие согласования сохраняются.
- Пока готовится запуск, редактирование запрещено. Нет вызовов Start/Pause, создания кампаний, загрузки контактов или платных проверок.
- Сохранённые request/launch_info завершённых запусков остаются историческими; последующий запуск читает актуальную цель из `ve_projects`.
