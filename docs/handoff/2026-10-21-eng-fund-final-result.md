Полное сравнение JSON подтвердило сохранность всех 534 прежних решений,

не подтверждена, один сайт недоступен. Удалённых/изменённых прежних решений нет.

Общий журнал Fund: 646 запросов `base_collect` на $0.139177 и один
`base_analyze` на $0.049255; все settled. После восстановления добавилось

заново или отдельных платных экспериментов не было.

На итоговой проверке `autopilot=false`; нет активных заданий писем,

## Независимая проверка качества

Конечные пять компаний точно соответствуют пяти accepted-verdicts.
У четырёх сохранённые материалы подтверждают собственную целевую услугу.
Одна компания погранична: доказанное хранение цифровых активов ещё не
доказывает именно выбранный банковский/фондовый подтип. Оба OK относятся
к этой пограничной компании; у четырёх уверенно подходящих — 10 catch-all.
Следовательно, все пять нельзя объявлять бесспорно подходящими для запуска.

Отдельно просмотрены 1110 сохранённых выдержек последних 60 компаний:

- один подтверждённый пропуск прямо разрешённого типа компании;
- четыре пограничных случая и пять с недостаточными материалами;
- один недоступный сайт и два несоответствия имени/описания сайта в источнике;
- 47 случаев без подтверждения выбранных услуг на имеющихся материалах,
  преимущественно с показанной другой деятельностью.

Подтверждённый пропуск: описание выбранной Fund Administrators явно включает
ManCos, сайт описывает саму компанию как фондовую управляющую компанию, и
модель признаёт эту роль, но затем требует дополнительно administration/
custody. Это ошибка применения выбранной альтернативы, а не обоснованный
вывод о непригодности. Не переносить этот вывод на остальных непринятых.
Частные отчёты содержат имена и основания; в Git полные цитаты не копируются.

## Новое уточнение кода, ещё не выложено

Изменён только текст classifier/reviewer в `engCompanyFit.ts`:

- каждая явно указанная альтернатива в полном описании проверяется до
  отрицательного решения; короткий заголовок её не сужает;
- управление активами, роль ManCo, администрирование и custody — разные
  деятельности; доказательство одной не подтверждает автоматически другую;
- когда ManCo явно включена, доказанная собственная роль не требует
  дополнительно admin/custody; обычный asset manager автоматически ManCo
  не становится;
- независимый reviewer получает ту же оговорку для явно выбранного типа.

Нет списка разрешённых компаний или KVG, автоматического допуска, изменения
стран, источника, бюджета, схемы/парсера решений, исторических вердиктов,
RU/VE2. Версия checkpoint не меняется: уже оплаченные решения не сбрасываются.

Перезапущены 45 существующих бесплатных сценариев с подменёнными внешними
вызовами. TypeScript core, ESLint, сборка HE и diff-check прошли. Независимый
review блокеров не нашёл. Новых `*.test.ts` нет. Это подтверждает совместимость
кода, **не** новое решение реальной модели: платного повтора не было.
Для фактической перепроверки пропущенной компании нужны отдельный разрешённый
шаг и проверка расходов. Сейчас она не добавлена в рабочую базу.
