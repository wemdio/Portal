# Общий поиск подтверждений на сайтах для гипотез VE2

## Задача и границы

Пользователь запросил улучшение получения доказательств для всех гипотез, а не только VBI / сетей клиник. Область изменения — общий website reader внутреннего VE2. ENG и `he_*` не меняются. Сам факт чтения страницы, ключевое слово в ссылке или наличие нескольких услуг не доказывают соответствие гипотезе: сохраняются действующие проверка принадлежности сайта, классификация по фактам и независимая смысловая проверка.

До изменения читались максимум две дополнительные страницы услуг; большой каталог мог вытеснить разделы о структуре компании. Таймаут не повторялся в пределах чтения сайта, а старое `needs_review` с использованной попыткой не попадало на улучшенную проверку автоматически.

## Поведение

- Единый ранжировщик ссылок учитывает условия гипотезы и общие разделы сайта: сведения о компании, подразделения и адреса, производственные площадки, продукты/услуги, проекты. Предпочтения по отрасли или названиям клиентов не заданы. Лексическое совпадение используется только для выбора страниц.
- Сначала читаются до трёх страниц, способных подтвердить принадлежность сайта. После этого — до четырёх дополнительных страниц деятельности. После каждой страницы учитываются новые ссылки: например, «О компании» → «Подразделения».
- Крупное меню товаров не вытесняет ссылки на реквизиты и компанию. Выбор дополнительных страниц учитывает уже просмотренные типы разделов. Навигационные меню сохраняются для поиска ссылок, но исключаются из текста о деятельности.
- Сохраняются пределы: 10 различных страниц, 40 секунд на один проход, один запрос поиска по ИНН. Внутри этих 40 секунд разрешены максимум два повтора временно неудавшихся чтений, не более одного повтора конкретного URL. Повторяются таймауты, распознанные сетевые сбои и HTTP 408/500/502/503/504; обычные ошибки контента/404 и запрещённые переходы не повторяются.
- Отмена прекращает дальнейшие запросы. Все сетевые попытки используют прежние ограничения URL, редиректов, DNS/public IP и объёма ответа. Неподтверждённый ИНН или найденный другой ИНН не разрешают использовать сведения с этого сайта. Конфликт на дополнительной странице аннулирует ранее полученные сведения с того же сайта.

## Сохранённые результаты

Новый `reader_revision: 2` добавлен к прежнему `reader_version: 1`: старый формат проверки принадлежности остаётся совместимым при откате. Контекст оплаченных классификаций и смысловых проверок не меняется.

Результат ограниченного уточнения отмечается `website_review_version: 2`. Сохранённые `needs_review` с подходящими email и доступным сайтом/ИНН, ещё не прошедшие этот механизм, получают один дополнительный проход при продолжении сбора. Успешные решения переиспользуются; незавершённое чтение/уточнение продолжается из checkpoint. Исчерпанная смысловая проверка остаётся в резерве и не запускает бесконечные поиски сайта. Строки без подходящих email не получают этот дополнительный расход только ради обновления версии.

Это не фоновый обход всех исторических баз: завершённая база без выполняемой задачи сама не запускается. Для остановленного VBI после выпуска нужно продолжить существующую подготовку базы.

## Проверка

В существующие тестовые сценарии добавлены реальные HTML/parser/reader fixtures для клиник, производителей оборудования и мебельной розницы, вложенных разделов и большого меню. Проверены конфликт ИНН на поздней странице, блокировка перехода на другой сайт, таймаут с успешным повтором, общий предел запросов/времени, отмена и обновление старого checkpoint без повторной оплаты успешной классификации. Новых тестовых файлов или `it()` нет.

Полный набор: 213 suites / 2 402 tests, около 56 секунд; TypeScript, ESLint и сборка воркера прошли. После финального уточнения ранжирования повторены проверки VE2 и изоляции ENG.

Production в этой задаче не изменялся. Увеличение фактического выхода контактов и результат VBI до 500 ещё требуют проверки после выпуска. Сайты только на JavaScript, недоступные страницы и неоднозначная принадлежность нескольким юрлицам могут по-прежнему остаться неподтверждёнными; критерии допуска не ослаблялись.
