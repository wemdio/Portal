# Ошибка разбора кейсов на коротких текстах

## Наблюдение

Специалист сообщил об одинаковой ошибке при вставке 2–3 тысяч символов в
«Добавить кейсы из текста». На скриншоте 2 027 символов при лимите 20 000.

Read-only проверка `application_logs` на production 14.09.2026 выявила семь
`tools.vertical-engine-v2.cases.structure_failed` с 09:58 до 10:09 UTC
(12:58–13:09 МСК) для проекта `f1ce1c75-2891-4cb5-ae94-c4e36b9e3cf5`.
Все семь ошибок: метрика срока внедрения (`duration`, `timeline`, «срок»,
«время внедрения») не прошла проверку цифр по исходному фрагменту.
Значения метрик и полный исходник в этих логах отсутствуют; точное преобразование
текста моделью по журналу установить нельзя. На момент первого исправления
оригинал был запрошен у пользователя; результат проверки полученного текста ниже.

## Причина в обработчике

`validateCaseDrafts` требовал хотя бы одну цифру в каждом значении `metrics`.
Поэтому даже дословный срок «несколько месяцев» отклонялся. Любая ошибка проверки
метрики останавливала весь импорт. Проверка исходных фрагментов выполнялась после
`callLLMWithSchema`, поэтому модель не получала обратную связь об этой ошибке.

API показывал одинаковый совет разделить текст при ошибке метрики, таймауте
или сбое провайдера. Размер исходника не был причиной семи ошибок из журнала.

## Исправление

- Словесные значения принимаются только как дословная фраза из фактической части
  своего кейса, с проверкой границ слов. Рекомендации и значения «не указано»
  не принимаются. Для цифр сохранена проверка наличия в исходном фрагменте.
- Промпт требует сохранять словесные сроки/количества дословно, без вычислений
  и преобразования слов в цифры.
- Проверки исходника включены в схему ответа. Ошибка может быть исправлена
  одной повторной генерацией полного набора; максимум два ответа модели
  в общем лимите API 45 секунд. Сохранение выбранного превью не вызывает ИИ.
- Неполный JSON повторяется целиком, без восстановления обрезанного массива.
  Реальное превышение 20 кейсов по-прежнему требует разделить исходник.
- API различает отмену (409), таймаут (504), неподтверждённый ответ ИИ (502)
  и прочие сбои сервиса (503). В лог добавлены размер текста, модель и безопасная
  диагностика схемы без исходного текста и ответа модели.

## Проверка и границы

В существующем тесте импорта проверены словесные сроки, цифры без основания,
рекомендации, частичное совпадение слова, исправление через реальный LLM-helper
с подменённым HTTP, остановка после двух неудачных ответов, неполный JSON,
лимит кейсов и разные ошибки API. Preview не пишет в БД; save повторно проверяет
исходник и не платит за повторную генерацию. Новые тестовые файлы и `it()`
не добавлены.

Изменён только внутренний Vertical Engine v2. Production не изменялся;
для применения нужен обычный деплой Portal.

## Проверка на присланном исходнике

В тот же день пользователь прислал текст отзыва о внедрении STARLIMS v.10
в ОАО «Пласткард» специалистами «Аврора-ИТ». Полученная вставка после trim —
1 996 символов, включая OCR-ошибки и переносы. Срок указан как «закончилось
через год». Производственная мощность 60 000 → 90 000 тн относится к предыдущей
модернизации завода, а не к результатам внедрения ЛИМС.

Локально выполнены два пробных разбора через реальный Requesty и настроенную
в Portal `openai/gpt-4o-mini`, с тем же ограничением 45 секунд. Каждый прогон
ограничен максимум двумя запросами к провайдеру. Кейсы в проект не сохранялись,
очереди, сервисы и production-код не менялись. Ключ использован только в памяти
процесса; исходник и ответы остались во временных локальных файлах вне Git.

- Код `7ad1273c2`: успех за 5 307 мс после двух ответов. Один кейс, корректные
  качественные результаты, но metrics оказался пустым, а исходный фрагмент
  не включил первую строку-заголовок. Срок оставался в исходном описании.
- После уточнения промпта о сохранении словесного срока и отделении справочных
  показателей клиента от эффекта выполненной работы: успех за 2 270 мс с первого
  ответа. Один кейс, полный исходник сохранён дословно, metrics:
  `{"срок внедрения":"через год"}`. Отрасль — производство поливинилхлорида;
  задача — внедрение STARLIMS для лабораторий ОТК. Рост мощности не приписан ЛИМС.

Requesty сообщил стоимости трёх ответов: $0.00038445, $0.00042585 и $0.0004137;
всего $0.001224. Эти единичные замеры подтверждают работу на данном тексте,
но не являются гарантией времени или качества для всех вставок.

В существующем тесте дополнительно проверен срок «через год» через перенос
строки, а также отклонение преобразований «1 год», «один год», «12 месяцев».
После уточнения: 18 проверок файла импорта и ESLint прошли.
