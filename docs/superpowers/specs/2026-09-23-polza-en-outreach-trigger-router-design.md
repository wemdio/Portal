# Английский автоаутрич v2 — trigger router (по en-outreach-flow-improvements CEO)

Дата: 2026-09-23. Ветка: `polza-eng-outreach`. Решение пользователя: всё в пользу предложения CEO.

## Поток

`компания → fit → поводы → данные → Lead Score → кейс → угол → цепочка`

1. **Кандидаты:** вакансии sales/GTM из `eng_hiring_cache` (SDR, BDR, AE, Growth, Partnerships, GTM, head/VP of sales) + стартапы YC из `funded_companies` (батч не старше заданного года, команда 3–200, страны формы, не consumer/education/government). Склейка по домену, затем по названию; компании с обоими поводами идут первыми. SEC Form D — этап 2 (нужна чистка от фондов/SPV).
2. **Домен и данные:** YC-домен или резолвер (кэш → PDL → Clearbit); PDL даёт размер, отрасль, страну.
3. **Жёсткие отсевы:** лидген-конкуренты, стаффинг/RPO/джоб-борды, маркетинговые агентства, B2C/образование, размер вне 3–200 (исключение «11–50» снято), дубль домена.
4. **Сайт и поводы:** один обход сайта + LLM (B2B-цитата, модель SaaS/service/platform, цитата ICP, дорогая сделка, исключения, контекст, вероятная GTM-боль, угол, 3 сегмента, отраслевая группа, недавний запуск с датой); стек продаж (HubSpot, Salesforce, Apollo, Clay, Instantly, Outreach, Lemlist) по коду страницы. Разбор вакансии подтверждает new-business sales/GTM функцию.
5. **Lead Score v1 (§3 CEO):** fit 40 + размер/страна 25 + повод 25 + данные 10. ≥75 write now, 55–74 manual check, ниже — skip (пороги в форме). Почта ищется только у write now, от сильных к слабым.
6. **Кейс:** общая с RU библиотека `polza_ru_cases`; нужен утверждённый кейс с английским текстом и совпадающей отраслевой группой. Черновики EN-текстов 6 кейсов — в миграции `20260923_0003`, без имени клиента.
7. **Письма (§5 CEO):** route to owner → боль и механика → кейс/сегменты/выборка 20–30 компаний → закрыть переписку. Обращение «Hi there,» (имени получателя нет), подпись Julia Mira. Цепочка 11.09 с гарантией «3 SQL или бесплатно» снята.
8. **Выгрузка:** поля персонализации CEO (primary_trigger, trigger_evidence_url, trigger_phrase, company_context, likely_gtm_problem, outreach_angle, recommended_case, case_reason, case_snippet, cta_type) + Lead Score.

## Вне этой версии

Проект «Signals» (`active/outreachos-signals`) в репозитории отсутствует — собственные аналоги. Этапы 2–6 CEO: SEC/новости об инвестициях, Product Hunt/HN/GitHub/Reddit, разбор ответов, связка с AMO и выручкой, ежедневный кокпит.
