# TG-аутрич: файлы и подчёркивание в первом сообщении

*28.09.2026. Запрос продаж (Егор): картинки/документы и форматирование в первом касании.*

## Решения пользователя
- Файлы загружаются к базе; в таблице базы необязательная колонка с заголовком «картинка»/«файл»/«вложение» (ищется по заголовку, не по номеру) — имя файла. Один файл базы можно отметить «для всех»: его получают контакты без своего файла.
- Файл и текст — одно сообщение (текст подписью под файлом). Картинки jpg/png (до 10 МБ) — фото, pdf/docx/xlsx/pptx/doc/xls/ppt (до 20 МБ) — документом. До 20 файлов на базу.
- Файлы только в первом касании; ответы ИИ и напоминания — текст.

## Устройство
- Таблица `tg_outreach_base_attachments` (файл, путь в хранилище, тип, «для всех» — один на базу), колонка `tg_outreach_base_contacts.attachment_name`, закрытый бакет `tg-outreach-attachments` (миграция 20260928_0003). Путь в хранилище — `{baseId}/{uuid}.{ext}`, имя для сверки с таблицей — в строке.
- API: `bases/[id]/attachments` (GET список + превью + «указан в таблице, но не загружен», POST загрузка), `bases/[id]/attachments/[attachmentId]` (PATCH «для всех», DELETE). Удаление базы чистит её файлы из хранилища.
- Отправка (`firstTouch/send.ts`): файлы баз порции читаются одним запросом, содержимое качается из хранилища один раз на порцию. Файл указан, но не загружен — контакт откладывается с попыткой и понятной причиной; хранилище не отдало файл — контакт остаётся в очереди без списания попытки. Отправка — `sendFile` с подписью и форматированием; без файла — `sendMessage`. В историю диалога — видимый текст и пометка о файле для ИИ.
- Разметка (`firstTouch/formatText.ts`) — свой разбор вместо встроенного markdown gramJS: `**жирный**`, `__курсив__`, `~~зачёркнутый~~`, `` `код` ``, ```` ```блок``` ```` как раньше, плюс `<u>подчёркнутый</u>` и `[текст](https://ссылка)` (во встроенной разметке gramJS ссылок и подчёркивания нет). Маркер без пары остаётся текстом. Длина проверяется по видимому тексту; с файлом — не больше 1024 знаков (предел подписи Telegram).
- Экран: у базы ссылка «файлы к сообщению» открывает блок загрузки, «для всех», удаления, предупреждения о ненайденных файлах и подсказку по разметке.

## Риски
- Одинаковая картинка сотням незнакомых людей может чаще ловить антиспам Telegram — сначала проверить на небольшой базе.
- Повторная загрузка таблицы не обновляет уже загруженные контакты (как и раньше): чтобы поменять файл у контакта, его поправляют в базе или удаляют и загружают заново.
