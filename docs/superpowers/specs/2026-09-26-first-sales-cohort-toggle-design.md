# Дашборд первички: переключатель «По когорте / Без когорты»

Дата: 26.09.2026. Ветка `dmitriy_kuladmed_new`. Просьба CEO через пользователя.

## Термины (как их называет CEO)

- **По когорте** (по умолчанию, текущее поведение после 25.09.2026): в период попадает всё, что в нём
  СЛУЧИЛОСЬ, в том числе по сделкам, заведённым раньше. Сделка из августа, оплаченная в сентябре, —
  деньги и продажа сентября; в таблице сделок она есть с меткой «заведена раньше».
- **Без когорты**: в период попадают только сделки, ЗАВЕДЁННЫЕ в периоде. Оплата, продажа, встреча
  по августовской сделке в сентябре не считаются.

## Что переключается

Всё на экране отвечает на один вопрос:
- плашки «Деньги», «Продажи», «Встречи» (лиды и квал и так считаются по дате создания);
- график по времени (корзины продаж/встреч);
- разбивки по источникам и менеджерам (включая столбец «Деньги»);
- таблица сделок под строкой (`/api/analytics/first-sales/leads`): без когорты — только `hits.lead`
  (как до 25.09.2026), без метки «заведена раньше»;
- воронка этапов (`stageFunnel.ts`): без когорты — только сделки, созданные в периоде (сейчас туда
  входят и сдвинутые в периоде);
- сравнение с прошлым периодом — в том же режиме.

## Деньги без когорты

Приходы по сделкам, заведённым до периода, не относятся к первичке периода, но и не пропадают:
новая строка под плашкой «по сделкам прошлых периодов: N ₽» (`MoneyTotals.earlierDeals`,
`earlierDealsPayments`), чтобы экран по-прежнему сходился с выпиской («всего по банку»).
Строка «ИНН у N из M продаж» считается по продажам текущего режима.

## Интерфейс и параметры

- Параметр запроса `cohort=0|1`, по умолчанию 1. Разбор в `lib/firstSales/params.ts` (поле
  `cohort: boolean`), передаётся во все ручки: summary, leads, stage-funnel.
- `FiltersState.cohort`, переключатель-сегмент в `FiltersBar` («По когорте» / «Без когорты») с
  подсказкой-пояснением; хранится в URL как остальные фильтры; входит в `drillKey`.
- Метрики — одной функцией с флагом (`computeFirstSalesSeries(..., { cohort })`), без второй копии
  логики: при `cohort=false` события сделки (продажа, встреча, деньги) засчитываются только если
  `isLeadInWindow(lead)`.
