# «Письма» в «Рассылке» как «Персонализированные ответы» — дизайн

Дата: 02.10.2026. Ветка: `dmitriy_kuladmed_new`.

## Зачем

Пользователь: вкладку «Письма» сделать как «Персонализированные ответы» — слева кампании, дальше
список диалогов с ящиками, по клику открывается переписка; и чтобы отвечать персонализированно на
русском и английском прямо здесь. Instantly и его кампании не подключать — только свои кампании
«Рассылки».

## Решения пользователя

- Бриф, тон и пример письма — **у каждой кампании** (шестерёнка в левой колонке), необязательны:
  без брифа ИИ опирается на нашу цепочку писем в переписке и общую базу знаний перс. ответов.

## Экран (components/sender)

- `ThreadsTab` — три колонки на всю ширину: кампании (статус, шестерёнка базы знаний, ящики
  выбранной) | переписки (поиск, «С ответами» — включён по умолчанию, «Только лиды», метки
  «Ответил»/«Лид», ящик, страницы с крутилкой) | открытая переписка. «Входящие без привязки» — под.
- `SenderReplyPanel` — лента писем, `LeadVerdictBar`, «Сгенерировать ответ / заново», «Рус / Англ»
  (запоминается на переписке), поле ответа (текст переживает перезагрузку), «Копировать»,
  «Отправить ответ» с подтверждением «уйдёт с ящика X на Y в эту же переписку». Пока ответ в очереди —
  переписка перечитывается раз в 5 с.
- `CampaignReplyKbModal` — бриф (можно из файла PDF/DOCX/TXT/MD), тон, пример.
- `ThreadModal` удалён — его заменила правая панель.

## Сервер

- `lib/senderReplies/draft.ts`: переписка из `sender_messages` (отправленные), `sender_replies`
  (human/unknown), `sender_manual_messages` (отправленные); цепочка — отправленные письма по шагам;
  промпт — общий `buildReplyPrompt` (типы входа ослаблены до `{companyName, leadEmail}` и
  тон/пример/факты — Instantly-вызовы не меняются), модель — `generateReplyWithSearch` (Gemini 3.1 Pro
  с поиском, ключ перс. ответов). Глобальные тон/пример/правила — из базы перс. ответов.
- Язык по умолчанию: английский у кампаний автоаутрича EN (`source_kind=polza_en` / папка `auto_en`),
  иначе русский.
- Ручки: `threads/[id]/draft` (GET открытый черновик и язык, POST сгенерировать, PUT язык),
  `campaigns/[id]/reply-kb` (GET/PUT), `threads/[id]/reply` принимает `draftId` и отмечает черновик
  отправленным, возвращает id письма.
- Миграция `20261002_0050_sender_reply_drafts.sql`: `sender_campaigns.reply_brief/reply_tone/reply_example`,
  `sender_recipients.reply_language`, таблица `sender_reply_drafts`.
