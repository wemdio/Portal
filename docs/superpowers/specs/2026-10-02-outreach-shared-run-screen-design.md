# Один экран запуска для английского и русского автоаутрича — дизайн

Дата: 02.10.2026. Ветка: `dmitriy_kuladmed_new`.

## Зачем

Пользователь: «интерфейс русского автоаутрича сделай полностью идентичным английскому, английский
удобнее; шаги поиска только в русском свои». Экраны разошлись: у русского окно этапа показывало
только отсеянных и примеры прошедших, таблица в 6 столбцов, раскрытая строка сплошным текстом,
не было «Показать отсеянные / Только готовые», CSV, живого обновления списка запусков.

## Решения пользователя

- **Один общий экран**, а не копия: правка экрана сразу попадает в оба языка.
- Столбцы английского, которых у русского нет (Вакансия, Услуга, Гео продаж, Уверенность), —
  **русские аналоги**: Повод (со ссылкой), Цепочка, Рынок, Доказательство A/B/C.

## Как устроено

`components/outreach/run/`:
- `OutreachRunView` — список запусков (живое обновление parser_jobs + опрос), загрузка
  результатов, фильтр «готовые / все / свой», клик по причине отсева, CSV и Excel, стоп, удаление
  с подтверждением, тост, панель запуска;
- `OutreachRunResults` — шаги, расход ИИ, плашки остановки, «Цепочки запуска», «Рассылка»,
  «Почему отсеивались» (кнопки-фильтры), таблица (Компания, Домен, 4 столбца языка, Почта,
  Письма, Статус), раскрытая строка (оценка + доказательства синим блоком слева, письма справа),
  пагинация;
- `OutreachStageModal` — окно шага «Компания / Что нашли / Итог», «Только отсеянные»;
- `types.ts` — `OutreachRunAdapter`: всё, чем языки различаются.

Адаптеры: `components/parsers/polzaOutreachAdapter.tsx` (EN, поведение прежнее) и
`components/polzaRuOutreach/ruAdapter.tsx` (RU).

## Русское, что сохранено

Шаги поиска (9 шагов, разбор шага — отсеянные полностью по ключу шага, прошедшие — примеры,
число из воронки), фильтры «Очень спорные» и «Ручная проверка», Excel «очень спорные» и журнал
(Excel по фильтру: готовые → ready, очень спорные → doubtful, иначе журнал), флаги сомнений под
статусом, «уже общались», AMO, оффер и второй вариант, ЦА-балл, все поводы с цитатами, тема Б,
ошибки источников, разбивка по цепочкам и SDR, пул/потолок просмотра, панель запуска с ползунками
и отправителями. «Библиотеки» — вкладка страницы рядом с «Запусками» и «Квалификацией».

## Сервер

- RU `results`: потолок страницы 500 → 1000 (`POLZA_RESULTS_MAX_PAGE`) — общий экран читает прогон
  страницами по 1000 и останавливается на короткой, иначе CSV обрезался бы.
- EN `results`: параметр `reason` (фильтр по `exclusion_reason`) — клик по причине отсева.

## Удалено

EN `PolzaOutreachResults`, `PolzaOutreachStageModal`, `PolzaOutreachStages`; RU `JobDetail`,
`JobList`, `Results`, `Stages`, неиспользуемое в `shared.ts`.
