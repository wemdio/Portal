# План: поиск контактных данных для ЛПР

## Текущая ситуация

- **ЕГРЮЛ** даёт только ФИО и должность; в коде контакты явно задаются как `null` (`leadImportWorker.ts` — `upsertDadataLprContact`).
- **Serper** ищет по запросу вида `"Название компании" руководство контакты телефон email` и вытаскивает из сниппетов ФИО и рядом стоящие phone/email.
- **Phone enrichment** работает только с `raw_leads.raw_phone`; на `company_contacts` (ЛПР из ЕГРЮЛ) не смотрит.
- **Парсинг сайта** находит людей на /team, /contacts, но не сопоставляет их с уже известными ЛПР из ЕГРЮЛ.

Итог: для ЛПР из ЕГРЮЛ **нет шага «найти для этого человека email, телефон или соцсети»**.

---

## Предлагаемые направления

### 1. Персональный поиск по ФИО + компания (Serper)

Для записей в `company_contacts` без `channel_phone`/`channel_email` выполнять запрос вида `"ФИО" "Компания" email телефон`, парсить сниппеты и обновлять контакты. Лимит запросов на джобу.

### 2. Привязка контактов с сайта к известным ЛПР (matching по ФИО)

При парсинге /team, /contacts сопоставлять найденных людей (ФИО + email/phone) с существующими `company_contacts` по нормализованному ФИО и обновлять записи.

### 3. Прогон телефонов из company_contacts через Telegram

Расширить `phoneEnrichmentWorker`: брать телефоны из `company_contacts`, прогонять через Telegram ImportContacts, обновлять `channel_tg_username` и `phone_identities`.

### 4. Email Finder API (опционально)

При наличии домена компании — вызов Hunter.io / Snov.io и т.п. по имени + фамилия + домен, запись в `channel_email`.

---

## 5. Пробив по соцсетям и прикрепление ссылок

**Цель:** для каждого ЛПР (особенно без email/телефона) искать профили в соцсетях; при нахождении сохранять ссылки на профили и показывать их в карточке контакта (в парсинге/обогащении «прикреплять ссылку»).

**Соцсети (поиск по ФИО + компания / должность):**

- **LinkedIn** — B2B, приоритет для директоров и менеджеров.
- **VK (ВКонтакте)** — массово в СНГ, часто есть контакт/ссылка в профиле.
- **Telegram** — уже есть `channel_tg_username`; при поиске по соцсетям можно находить публичные каналы/профили и сохранять ссылку (t.me/username).
- **Facebook** — реже в B2B, но возможен поиск.
- **Twitter/X** — публичные аккаунты, ссылка в профиле.
- **OK (Одноклассники)** — распространён в СНГ.
- **Habr (habr.com)** — для IT/руководителей разработки.
- **Instagram** — опционально (часто личный).
- **WhatsApp** — при наличии телефона ссылка `wa.me/<number>` может генерироваться на фронте; отдельный «поиск» не нужен.

**Реализация:**

1. **Хранение ссылок**
   - Вариант A: одна колонка `profile_links` (jsonb), например `{ "linkedin": "https://...", "vk": "https://...", "telegram": "https://t.me/..." }`.
   - Вариант B: отдельные колонки `linkedin_url`, `vk_url`, `telegram_profile_url` и т.д.
   - Рекомендация: **jsonb `profile_links`** — гибко, без миграции при добавлении новой сети; в API отдавать как объект, на фронте рендерить иконки и ссылки по ключам.

2. **Миграция**
   - Добавить в `company_contacts` поле `profile_links jsonb` (или выбранный вариант). Обновить RLS при необходимости.

3. **Поиск профилей**
   - Источник: Serper (или аналог) по запросам вида `"Феоктистов Петр" "В2-ГРУПП" linkedin` / `site:linkedin.com "Феоктистов Петр"`; то же для `site:vk.com`, `site:facebook.com`, `site:t.me`, `site:ok.ru`, `site:habr.com`, `site:twitter.com` (X) и т.д.
   - Парсинг ответов: из `results` брать `link`, проверять домен (linkedin.com, vk.com, facebook.com, t.me, ok.ru, habr.com, twitter.com, x.com, instagram.com), при необходимости проверять релевантность по snippet (ФИО/название компании). Один запрос на сеть на человека или один комбинированный запрос с несколькими site: — в зависимости от лимитов и качества.
   - Запись: для каждой найденной ссылки добавлять в `profile_links` ключ (linkedin, vk, telegram, facebook, twitter, ok, habr, instagram) и URL. Upsert по `(user_id, company_id, full_name)`.

4. **Цепочка**
   - Новый шаг в постобработке (например, `runSocialProfileEnrichment(jobId, userId)` после Serper/сайта): выборка контактов без контактов или с приоритетом ЛПР (ceo/director), лимит на количество запросов Serper на джобу, вызов поиска по сетям, парсинг и обновление `company_contacts.profile_links`.

5. **Фронт (CIS Lead Finder)**
   - В API контактов добавить в `select` поле `profile_links`.
   - В карточке контакта: блок «Соцсети» / «Профили» — иконки и ссылки по ключам из `profile_links` (открытие в новой вкладке).

**Ограничения:** лимиты Serper; часть запросов не вернёт результат; нужна нормализация URL (убирать лишние query-параметры при сохранении).

## Рекомендуемый порядок внедрения

| Шаг | Что делаем |
|-----|------------|
| 1 | Персональный Serper по ФИО+компания (email/телефон) |
| 2 | Matching контактов с сайта с ЛПР по ФИО |
| 3 | Прогон телефонов из company_contacts через Telegram |
| 4 | **Пробив по соцсетям: миграция (profile_links), воркер поиска, парсинг ссылок, вывод в UI** |
| 5 | (По желанию) Email Finder API |

Технически: новый шаг в `runLeadPostProcessingInternal` для (1); доработка `websiteTeamParser` для (2); расширение `phoneEnrichmentWorker` для (3); миграция + `socialProfileEnrichment` (или аналог) + обновление API и страницы cis-lead-finder для (4).
