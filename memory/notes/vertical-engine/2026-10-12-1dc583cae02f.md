После вопроса пользователя о жалобе специалиста проверен код a929b2eb2. В основном AutoOutreachProject карточка BaseRow скачивает mode=preview для автоматически собранной preview-базы. API после проверки и project exclusions делает slice(0, VE_PREVIEW_READY_TARGET), константа 500. Поэтому «скачать все превью» не означает скачать все готовые контакты, если база больше 500.

Полный launch-ready API существует и фильтрует exclusions, но его кнопка находится в старом Step5Template и требует шаблон, аудит, клиентский пресет. Новый OutreachLaunchPanel использует только отдельные hooks/блоки из него и не выводит эту кнопку. Единой выгрузки всех гипотез также нет. Это подтверждённый пробел нового UX, а не отсутствие сохранённых контактов. Изменение в этом диагностическом ответе не делалось; production не проверялся и не менялся.

Не обещать специалисту «всю очищенную базу» через CSV превью. Для такого сценария нужна отдельная доступная кнопка всех проверенных контактов без preview cap, с теми же exclusions и readiness gates; не подменять raw-выгрузкой кандидатов.
