# Противоречащие источники

`wiki/concepts/key-metrics.md` описывает `contacted_count` как уникальных лидов, получивших хотя бы одно письмо. `wiki/playbook.md` утверждает, что это число событий отправки, и предлагает `new_leads_contacted_count` для знаменателя уникальных лидов.

Подтверждено наличие противоречия. Правильная интерпретация в рамках этой задачи **не установлена**. Нельзя выбирать одну из формул только по уверенной формулировке страницы.

# Следующая проверка

Для конкретной аналитической задачи проверить текущий контракт источника и путь синхронизации, затем сопоставить оба поля на согласованной выборке и периоде с независимо посчитанными уникальными контактами. Указать кампании/срез, единицу и границы периода. После подтверждения согласовать определения в канонической wiki, обновить эту запись через проверку хеша, сохранив происхождение исправления.

До проверки явно указывать знаменатель отчёта и ограничение, если результат зависит от спорного поля. Этот вопрос не блокирует анализ других подтверждённых метрик.
