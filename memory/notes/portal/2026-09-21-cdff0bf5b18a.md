## Коррекция пользователя

Проектный тег `Вороной` существует. Теги `неименные почты` и `неименные maildoso` имеют одинаковую роль: это два резервных пула, а не проекты. Скриншот пользователя показывает ящики с одновременными резервным и проектным тегами.

## Read-only проверка live Instantly

- ID проектного тега `Вороной`: `39598b21-7c31-4486-966f-62197bd7ef55`.
- ID резервного тега `неименные почты`: `1893a2a1-cbc8-4029-a4c5-73982c3bf259`.
- ID резервного тега `неименные maildoso`: `c4d66cdf-7ddc-467d-92e8-b45fbb57934f`.
- Все девять активных кампаний проекта «Вороной» настроены только на резервный тег `неименные почты`; ни одна не использует тег `Вороной`; у всех `email_list` пуст.
- Фильтр list-endpoint Instantly для этой проверки оказался ненадёжным и был отброшен; итог подтверждён прямым GET каждой из девяти кампаний.

## Вывод

Безопасная точечная production-коррекция для этих девяти кампаний — заменить `email_tag_list` с резервного тега на единственный проектный тег `Вороной`, сохранив остальные настройки. Выполнение требует отдельного явного разрешения непосредственно перед PATCH-записями.
