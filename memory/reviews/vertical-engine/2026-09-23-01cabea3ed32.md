## Повторная проверка по просьбе пользователя

Продолжение [предыдущего итога](2026-09-23-e643d5026008.md). Проверен весь незакоммиченный diff на базе `40ef24bc4` в `codex/ve2-preview-recovery-scale`.

Найдены и исправлены проблемы первоначальной реализации `checkLetterPresentation`:
- Новый общий greeting regex отвергал естественные EN/PL-приветствия (`Good evening`, `Dobry wieczór`). В актуальной финальной генерации закрытый список приветствий теперь применяется только к RU. Legacy non-RU greeting check сохранён отдельно с прежней семантикой.
- RU-приветствие с NBSP между словами ошибочно отклонялось; принимаются горизонтальные пробелы, включая NBSP.
- RU-приветствие с приклеенным после `!` текстом проходило: regex теперь проверяет строку целиком, допускает имя/оператор после запятой и инициалы.
- Пустые абзацы из пробельных строк могли учитываться как содержательные: при разбиении они отфильтрованы.
- Пример структуры в `prompts/finalLetters.ts` теперь использует приветствие на выбранном языке, чтобы русский пример не влиял на EN/PL.
