# Что проверялось

Пользователь попросил перепроверить качество первой версии памяти. Проверены helper, навык, подключение в основной папке и другой Git-worktree, порядок записей, авторство и сохранность прежних правил проекта.

# Найдено и исправлено

1. В версии `065acd91c` персональный helper и его копия в другом worktree выбирали разные каталоги памяти. Теперь основной worktree определяется через локальный Git; команда `where` показывает общий корень. При отсутствии общего хранилища нет скрытого перехода на частную копию.
2. Проверка структуры обходила только один уровень каталогов и могла сообщить «OK: 0 records» для существующей заметки в неправильном каталоге. Теперь Markdown-записи проверяются рекурсивно, ошибка содержит путь.
3. Новые записи одного дня сортировались по имени файла; случайный идентификатор мог скрыть последнюю запись из ограниченной выдачи. Добавлены точное время создания/изменения и сортировка по нему. Старые записи только с датой поддерживаются; их порядок внутри дня неизвестен.
4. Автор захвата по умолчанию был `codex`, даже для Claude. Теперь автор обязателен при создании и правке. Правка сохраняет автора создания, указывает автора/время изменения и хеш предыдущего содержимого. Дата проверки источников не обновляется автоматически.

# Доказательства

Четыре воспроизводящих теста сначала завершились ошибкой на первой реализации. После исправлений проходят 16 тестов, включая временный Git-репозиторий с двумя настоящими worktree, две конкурирующие записи, временной порядок, авторство, структуру и защиту путей. Валидатор навыка и проверка локальных ссылок пройдены. Обе установленные точки входа проверены из папки v2 и возвращают один корень памяти. Существующие SSH- и ENG/v2-правила в основной папке сохранены.

# Коррекция предыдущего вывода

[Первоначальная проверка](2026-09-13-initial-review.md) подтверждала ограниченный набор сценариев. Проверка только персональной символической ссылки не доказывала общность хранилища для двух копий helper в разных Git-worktree. Для дальнейших изменений сохранять этот регрессионный сценарий.

# Границы уверенности

Проверен локальный механизм памяти на macOS. Это не замер улучшения качества ответов следующих агентов и не автоматическая проверка истинности записей со статусом verified. Соблюдение навыка агентом остаётся частью рабочего процесса; фонового расписания и подключения к продуктовым LLM-пайплайнам нет. История предыдущего содержимого сохраняется в Git только после коммита; один хеш не заменяет её.

Данные production и определения спорных метрик Instantly этой проверкой не менялись. Полезность для Движка и аналитики следует измерять на последующих задачах.
