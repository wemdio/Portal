Специалист сообщил о повторяющейся ошибке разбора кейсов при вставке 2–3 тысяч символов. Screenshot показывает 2 027 / 20 000. Read-only production `application_logs` за 14.09.2026: семь structure_failed в 09:58–10:09 UTC, project f1ce1c75-2891-4cb5-ae94-c4e36b9e3cf5; все — метрика срока внедрения (`duration`, `timeline`, «срок», «время внедрения») не прошла проверку цифр. Полного текста и значений метрик в логах нет; пользователь пока ищет исходник. Нельзя утверждать, какое именно значение вернула модель на его тексте.

В caseBank.ts подтверждён дефект: любое значение metrics без арабской цифры отвергалось, даже дословное «несколько месяцев». Проверка исходника выполнялась после callLLMWithSchema и не попадала в его feedback/retry. API скрывал метрики, таймауты и сбои провайдера за одним советом разделить текст.

Исправлено: словесные значения принимаются только как дословная фраза из фактической части своего кейса с границами слов, без рекомендаций/заглушек. Числовые показатели по-прежнему сверяются с исходником; преобразования слов в цифры не принимаются. Промпт уточнён. Проверки исходника включены в схему ответа; одна попытка исправить полный набор, максимум два ответа под общим deadline 45 секунд. requireCompleteJson=true не позволяет принять восстановленный обрезанный массив. Реальные >20 кейсов требуют разделения. Preview не сохраняет, save не вызывает ИИ.

API различает отмену 409, таймаут 504, неподтверждённый ответ ИИ 502, прочие сбои 503. Для validation error журнал пишет безопасное описание, размер текста, модель и статические пути схемы, без ответа модели/исходника.

Проверка: существующий briefInLetterPrompts.test.ts — словесные сроки, рекомендации, неподтверждённые цифры, частичное слово, реальный LLM-helper с HTTP mock исправляет первый ответ и останавливается после двух неудач, неполный JSON, отсутствие DB inserts при провале, разные API ошибки. Не добавлены файлы тестов или it(). Полный Jest: 213 suites / 2402 tests, 54.968 s; TypeScript и ESLint passed. Детали: docs/incidents/2026-09-14-ve2-case-import-metrics.md.

Область только внутренний VE2; ENG не затронут. Код подготовлен к коммиту/пушу Sergey от 46ad0e515. Production не изменялся, нужен обычный деплой Portal. Проверка реальным провайдером на исходном тексте специалиста не выполнялась и остаётся отдельным шагом после получения текста.
