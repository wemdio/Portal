В ходе проверки noon-release 2026-09-17 (production a28573be9, code ad2bb1227) три остановленных превью Эво возобновлены с прежними base IDs; подготовка названий у «Сладостей» стала complete, 412→437 готовых при неизменных 2635 обработанных кандидатах.

При попытке точечного продолжения через карточку обнаружено: AutoOutreachProject передавал только action=prepare, и ve_request_outreach_preparation возобновлял все выбранные ошибочные гипотезы проекта. Два нажатия затронули семь остановленных гипотез вместо намеченных трёх; все базы созданы накануне, новые базы не созданы. Дополнительные четыре запуска вне fixed21 отмечены пользователю и в приватном отчёте; нельзя отчитываться как о ровно трёх перезапусках. После обнаружения новых нажатий не было.

Исправление: кнопки карточки и писем передают hypothesis_id; API валидирует его и вызывает отдельный ve_request_outreach_hypothesis_preparation RPC. Проверяет текущую revision, принадлежность и выбор гипотезы, язык; сохраняет base/template IDs, не меняет siblings, ready остаётся ready. Общая подготовка выбора сохраняет прежнюю команду. RPC доступен только service_role.

Проверка: 225 suites / 2473 tests за 60.215 s, TypeScript и scoped ESLint pass; расширен существующий тест без новых cases/files. Новая SQL-функция реально выполнена локально в PGlite: изоляция строк, сохранение ID, готовый результат, ошибочные revision/project/hypothesis/language и grants проверены. Этот следующий UI/API фикс на момент записи ещё не выпущен; фактический deploy необходимо сверить.
