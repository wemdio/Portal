Продолжение решения notes/vertical-engine/2026-10-07-a37fedd0e4ef.md: пользователь согласовал общий бюджет автоматического поискового добора **до $3/сутки для всех VE2 проектов** и добавление проверок в существующие тесты. Это не разрешение на production-записи, нагрузочный прогон или деплой.

Реализованы SQL-очередь с lease/fencing для dedicated/legacy/DFYB исполнителей, приоритет ручных задач, общая ёмкость 5 и максимум 1 автоматическая задача; максимум 20 автоматических задач в очереди. Ограниченный VE2 fallback после остановки обычных источников: 10 SERP-сайтов на пробу, максимум 3 страницы на гипотезу/запрос/язык, последующая страница только при приросте готовых контактов. Никакого полного ручного crawl/LLM query expansion из автоматики. Исторические кандидаты не открываются повторной платной волной. Готовность требует штатных email/relevance проверок.

Защищённая таблица отмечает базы для единого бюджета. RPC резервирует деньги перед каждым учитываемым платным вызовом для таких баз, включая последующие VE2-проверки. Скользящие 24 часа; неизвестный результат сохраняет резерв; неизвестный тариф запрещает запрос. Превышение заявленной стоимости над резервом блокирует следующие расходы. Сбой DB-чтения очереди откладывается без траты попытки, начатый SERP с неизвестным ответом автоматически не покупается повторно. Удаление базы не стирает расходы и не превращает пробу в ручную задачу.

Найденный при проверке риск обычного поиска: out-of-order завершение параллельных запросов двигало общий processed_queries за незаконченный запрос. Теперь сохраняется непрерывный префикс; результаты записываются с fencing и дедупликацией, ошибка сохранения не завершает запрос успешно. DFYB enqueue получил детерминированный ID.

Локально: 51 suite / 525 passed (1 ранее skipped), последующие 115 и 39 точечных проверок; strict TypeScript, ESLint, сборка трёх воркеров; миграция выполнена в PGlite с проверками прав/бюджета/lease. Не было платных вызовов, production-записей, реальной многопроцессной/нагрузочной проверки. Новый тестовый файл не создавался.

Миграция обязательна до новых воркеров; все исполнители должны обновиться вместе. Автодобор оставлен disabled по умолчанию; после деплоя нужны read-only проверка очереди и отдельно разрешённое включение с $3. Существующие завершённые базы не перезапускаются.
