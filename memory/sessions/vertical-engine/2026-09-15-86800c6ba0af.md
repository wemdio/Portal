- Последний constructor cee3a02a-b619-415c-b2f1-39c5b6266fca: completed, input 1071, validate output 0 за 23–32ms. Сам итоговый emails_found=0 считает финальный результат; отдельно он не доказывает отсутствие найденных адресов.
