not a live parser. Read-only production diagnostics confirmed two failed recent
previews had search_urls parser jobs without catalog_filters; proxy errors were
caused by the wrong VE2 dispatch path.

RPC, real dictionary mapping, atomic cursor+harvest checkpoints, bounded pages,
and reuse of the same failed preview on explicit continuation. Legacy parser
IDs/results are preserved; old cancelled preparations are not revived. Company
cache work by the other developer and ENG/hypothesisEngine were not changed.

configured OpenAI gate/review models; citation selection has only evidence_ids.

failure breaker. Unconfirmed companies stay in reserve, never admitted. Paid
successful checkpoints and exhausted prior repair reservations are preserved.

with explicit IDs and a shortlist ranked by distinctive query terms. Repeated

read-only catalog queries returned HTTP 200 with three rows each. Native
gpt-5-mini review and citation schemas succeeded. Total reported probe usage
across both local runs USD0.00870055. No production records/services mutated.
