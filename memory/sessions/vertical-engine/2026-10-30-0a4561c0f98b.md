Запрос пользователя: поднять TinyFish Fetch до 1000 обращений, при исчерпании квоты пропускать TinyFish и продолжать обычное чтение/собственный браузер, без платного продолжения.

Локальная реализация в Sergey:
- `engTinyfishFallback.ts`: проверка provider usage текущего UTC-дня пропускает Fetch начиная с 1000. Live-rate gate по-прежнему требует ровно нулевую USD-цену за URL.
- Новая миграция `20261030_0001_eng_tinyfish_daily_limit.sql` заменяет RPC: общий предел 1000 за скользящие 24 часа, прежние 120 за минуту. Массив reservations и права вызова сохраняются; старую применённую миграцию не редактировали.
- Логика продолжения уже была: при quota/price отказе TinyFish возвращает null, сохраняется имеющийся HTTP/browser результат; следующий сайт по-прежнему может читаться своим браузером. Повторного платного вызова и автоматической пересборки ранее пропущенных страниц нет.

Проверки: offline-вызовы реальных функций для usage 999/1000/1001, ненулевой/неизвестной цены, отсутствия резерва, HTTP 429 без повторения, сохранения browser HTML и чтения следующего сайта. SQL исполнен на PGlite PostgreSQL 18.6: 9 проверок, включая сохранение старых reservations, границы 1000/120, истечение 24 часов и отказ anon/authenticated. PGlite не имитирует многосессионную конкуренцию production PostgreSQL 15. ESLint и 5 существующих migration grant checks прошли.

Контекст условий TinyFish на 30.10.2026: официального разрешения суммировать бесплатные квоты через смену аккаунтов не найдено; Organizations делит общий лимит, а Terms Restrictions(d) запрещает обход usage rules без письменного разрешения. Ротация не добавлялась. Источники: https://www.tinyfish.ai/terms ; https://docs.tinyfish.ai/key-concepts/organizations.md#shared-limits . Это наблюдение о текущих условиях, не новое разрешение или постоянное правило.

Production не менялся. Для применения нужны обычный выпуск и новая миграция; эта запись не подтверждает их выполнение. Данные клиентов, ключи и контактные адреса не сохранялись.

Полная проверка типов: все пять конфигураций TypeScript 7 прошли. Локальный alias typescript-7 отсутствовал, резервный TypeScript 5 упёрся в стандартный heap 4 GiB. Для проверки точный typescript@7.0.2 из lockfile установлен во временную папку с --ignore-scripts; версия и integrity сверены. Зависимости/lockfile репозитория не менялись.
