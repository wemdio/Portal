# Уточнение StaffLine: общие почты и отдельная проверка кампаний

Пользователь подтвердил: сам поставил StaffLine на паузу для проверки, ожидает подготовку без отправки. Почты также используются в ручных кампаниях — это нормальная схема.

Исправляет вывод сессии `memory/sessions/vertical-engine/2026-09-28-b6d7c6b632df.md`: реальное пересечение 20/20 не означает отсутствие доступной мощности и не требует отвязывать почты. По официальной документации Instantly https://help.instantly.ai/en/articles/6248612-account-and-campaign-limits дневной лимит аккаунта применяется суммарно ко всем его кампаниям. Расчёт Portal — верхняя граница; фактическая доля может быть ниже из-за других отправок.

Код после de9ebbd0f, ветка codex/ve2-preview-recovery-scale, доставка в Sergey: contactDeliveryRate больше не исключает общие почты; busy_mailboxes сохранён как информационный счётчик, интерфейс объясняет общий лимит. Аккаунты и внешние кампании не меняются. Теговый lookup и проверки полноты данных сохраняются.

Найдено и исправлено: outreachLaunch подставлял confirm_campaign_review=true и активировал после создания. Теперь основной поток только готовит кампании без отправки и ждёт отдельного подтверждения специалиста в «Очереди запусков». Повторный проход воркера не активирует кампанию. До подтверждения контакты остаются в резерве Portal; первая загрузка идёт после подтверждения. Кнопка переименована в «Подготовить кампании в Instantly». Уже активные запуски сохраняют состояние; ручная пауза уже запускавшейся кампании автоматически не снимается.

Проверка: 45 тестов / 7 существующих наборов, полный typecheck:strict, ESLint, esbuild worker. Существующие тесты дополнены без новых файлов/it. Отдельно contactDeliveryRecovery подтверждает сохранение ручной паузы; outreachLaunchWithoutPeriod проверяет ожидание, повторный проход и переход только после внешнего подтверждения очереди.

Production в этом исправлении не читался и не менялся; новая информация об инициаторе паузы получена от пользователя. Платных API не вызывали. Деплой отдельный; автоматическое возобновление паузы не разрешено. Подробности: docs/handoff/2026-09-28-ve2-rate-tags-and-stock.md.
