Добавлена обработка заполнения тарифа Instantly для суточной доставки VE2. Пользователь отдельно согласовал дополнение существующих тестов; новых файлов тестов нет. Направление публикации — Sergey по явной просьбе пользователя в этой задаче. Production-записи и деплой не выполнялись.

- Предварительная проверка GET `/workspace-billing/plan-details` читает `subscriptions.outreach.total_lead_limit/current_lead_count`. Неизвестное значение и недоступный billing scope не означают ноль; при временной недоступности используется ответ импорта. Обычный HTTP 402 не доказывает заполнение: в официальном контракте это может быть отсутствие платного плана.
- `remaining_in_plan = 0` при частичном успехе раньше превращал остаток в окончательные skipped. VE2 теперь сохраняет точные accepted и безопасно возвращает точно не загруженные строки в ready. При неизвестных identity или транспортном сбое строки остаются uncertain, повтор запрещён.
- Миграция `20260924_0013_ve_instantly_upload_capacity.sql` атомарно сохраняет паузу с исходом попытки; закрывает stale worker snapshots; возобновление проверяет версию паузы, срок проекта и согласование. Неотправленные соседние партии остаются reserved. В тот же день дозаливка использует исходный резерв; на следующий — обычный дневной расчёт. Переигрывание ответа finalize после resume не создаёт паузу повторно.
- Карточки кампаний (включая импортированные базы) показывают причину, загруженное/оставшееся/неопределённое количество и кнопку «Дозалить контакты проекта». GET/POST `/templates/:id/upload` работает через внутреннюю авторизацию и проект из сохранённого шаблона. POST не вызывает Instantly, работу выполняет очередной проход VE2 worker (по умолчанию 5 минут). Уже принятые контакты продолжают проходить обычную активацию.
- Общий append меняет режим только при `pauseOnWorkspaceCapacity: true` (VE2); ENG/прочие вызовы сохраняют прежнее поведение.

Проверки: все 3169 тестов / 289 suites, TypeScript, сборка VE2 worker; реальный PostgreSQL через локальный PGlite проверяет исходную квоту, частичную загрузку, исключение accepted/skipped/uncertain из retry, повторные клики/ответы, смену дня и закрытый проект. Локальный браузер: статус и кнопка, узкая колонка, светлая/тёмная тема; API подменён только в временном макете вне репозитория. Требуется миграция + деплой приложения и VE2 worker; живые контакты не загружались.
