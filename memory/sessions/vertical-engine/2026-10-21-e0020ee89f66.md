Запрос: только ENG — 500 готовых контактов и ещё 2–5 тысяч в запасе, с добором и обычным поиском, общий лимит $5 на базу. Пользователь подтвердил тариф Serper: 50 000 кредитов за $50, то есть $1/1000.

Подготовлен новый opt-in путь только для новых ручных клиентских ENG-баз: по умолчанию 500+2000 реально проверенных уникальных адресов, OK перед catch-all, прежний замороженный лимит компании (default 5), одна база и один денежный журнал. Волны 100, затем 50–200 компаний по фактической отдаче; проверка компаний до сбора/валидации адресов. Обычный поиск чередуется с каталогами. Google Maps исключён из нового планировщика до включения его дочернего задания в общий бюджет. Нельзя выводить страну из поискового запроса/TLD; размер и соответствие гипотезе не ослаблены.

Настоящий запас хранится отдельно от первых 500; лениво используется существующим разрешённым refill, без запуска писем. Claim/manifest/recovery/settlement защищены версией строки. При сбое неизвестными становятся только фактически подготовленные к отправке адреса, нетронутый запас сохраняется. Прежний срок свежести 7 суток сохранён. Показатель Reserve collected означает первоначально подготовленный запас, а не текущий остаток после отправки.

Полные проверки оплаченных исторических данных не повторяли. Завершённый audit сжимается до цитат решения и доказательств с хешем исходных цитат; на сохранённых 594 решениях 4.88 MB→1.73 MB. Стоп перед новой платной волной при 16 MiB истории. Это не миграция исторических баз. Остановка по бюджету сохраняет уже оплаченный результат и не покупает волну повторно.

Проверка: 155 offline проверок реального collection stage, 87 helper, 82 search, 43 reserve, 40 country/size, 14 UI, 45 existing qualification; 47 существующих Jest тестов; core/API/pages TypeScript, ESLint и HE worker build. Offline mock 500+2000 проверяет переходы, а не доказанный выход реального HST. Все эксперименты этой разработки $0. Новых repository test файлов нет. RU/VE2, production, письма не менялись. Код ещё не выложен; реальный HST yield требует разрешённого нового сбора после деплоя пользователем.
