StaffLine / «Энергетические компании»: read-only production audit ready, summary.status=not_required, default.count=774, segments=[], launch_status=idle. Это одна общая кампания, а не 0. На момент проверки запусков проекта нет.

В OutreachLaunchPanel было два дефекта: ad-hoc API type ожидал defaultGroup вместо сохранённого default; параллельный delivery-preview начинался на working audit, оставляя incomplete при ready preflight с тем же ID. Исправлены канонический тип и использование одного preview из текущего prepare-launch. Общий Step5 сохраняет собственную проверку. UI фикстуры следует сверять с реальным API-контрактом: прежний локальный fixture с выдуманным defaultGroup маскировал дефект.

29 существующих тестов, TS core/tests и ESLint прошли. Изолированный jsdom harness воспроизводит race на старом HEAD и проходит после правки: смена цели, запоздалый ответ, истинная ошибка и сброс согласия также проверены. Новых it()/постоянных test-файлов нет. Нет production mutations, запусков или платных запросов. Требуется обычный UI деплой; повторный сбор/аудит не нужен.
