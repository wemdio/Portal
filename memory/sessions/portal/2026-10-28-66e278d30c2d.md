# Яндекс.Карты: согласование очереди, отмена запросов и продолжение

## Запрос и граница
Пользователь попросил исправить параллельность/ожидание, подготовить коммит и пуш в Sergey; затем возобновить задачи с сохранённого места. Небольшой набор изолированных регрессионных тестов отдельно одобрен. Production, конфигурация ресурсов и состояния задач в этой сессии не менялись; деплой/возобновление остаются отдельной фазой.

## Реализовано и проверено локально
- В клиенте один FIFO на процесс воркера для всех parse-orgs (включая обход каталога), ёмкость из /health.parse_concurrency, безопасный fallback 2 для старого сервиса. Предыдущая диагностика выявила 8 производителей на задачу против фактических 2 слотов Python (legacy YANDEXMAPS_CONCURRENCY).
- У задач heartbeat раз в 30 секунд с условием status=running и started_at текущего запуска. Потеря владения отменяет запросы и удаляет ожидающие из очереди. Поздние ответы не обновляют состояние нового запуска.
- Вложенные HTTP-повторы parse-orgs удалены; ограниченные повторы со сменой прокси остаются в воркере. После ошибки сохранения нет повторного сбора и двойного счёта, параллельные запросы отменяются и дожидаются завершения перед финальным статусом.
- Python-дедлайн охватывает очередь, старт браузера и парсинг; disconnect отменяет работу и освобождает слот после ограниченной очистки.
- Сохранённые card_url исключаются из продолжения, strict_max_results сохраняется. Непройденные заблокированные пачки больше не превращаются в completed только из-за того, что их меньше трёх.

## Проверка
Jest: очередь/отмена/HTTP body timeout/health capacity/fencing/resume/ошибка сохранения, без внешних запросов. Python unittest: очередь и startup timeout, disconnect активного/ожидающего запроса, cleanup при успехе/ошибке. Все целевые тесты прошли; ESLint и esbuild worker прошли. Прицельный TypeScript 5 с исходниками, воркером, тестами и транзитивными зависимостями прошёл. Полная проверка типов приложения не завершена: локально отсутствует typescript-7, полный TS5 route-validator исчерпал стандартный heap 4 ГБ. Это не выдаётся за успешную полную проверку.

## Релиз
База правки: origin/Sergey f1430b7ca81a1a28c652eb5370ab3e45179deb55, отдельный существующий task worktree. Миграций и compose-правок нет. Нужны новые образы worker-yandexmaps и Python yandexmaps. Текущий select-deploy-targets.sh для общих app/* выбирает Portal и весь пул воркеров, а для services/yandexmaps/* — yandexmaps: штатный деплой не является изолированным рестартом только Яндекс.Карт. Правила селектора в рамках этого исправления не менялись. Перед возобновлением проверить версии/health и актуальное состояние задач; не запускать повторный сбор ссылок и не очищать сохранённые организации.
