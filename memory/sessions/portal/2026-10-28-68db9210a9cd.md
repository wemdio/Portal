## Финальная перепроверка перед разрешённым пушем

Пользователь явно разрешил перепроверку, исправления, коммит и push в `Sergey` (29.10.2026). Разрешение не распространяется на release/deploy или production-миграции.

В ревью найден и исправлен реальный race: runner возвращал DOM через фиксированные900мс, пока JS-fetch ещё мог получить403 позже. Теперь runner учитывает активные route-запросы, ждёт окно сетевого покоя (1с, общий срок settle8с), повторно проверяет отсутствие запросов после чтения DOM. Broker независимо считает pending/fetch и отвергает success при незавершённом чтении. Timeout, потерянный ответ, incomplete и generic unavailable терминальны для цепочки. TinyFish допускается только после проверенной пустой страницы, busy/not_ready до сети либо наблюдённого5xx первоначального prefetch; 5xx подресурса терминален.

Второй найденный дефект: очистка контекста могла зависнуть после снятия основного таймера и оставить runner занятым навсегда. Независимый watchdog2с теперь завершает процесс при зависшем close(); контейнер перезапускается с закрытой изоляцией.

- Отложенный403 через2,5с → blocked, DOM отсутствует; отложенный JSON → DOM содержит результат; зависшийfetch → incomplete без DOM; подменный runner с раннимsuccess при pending/fetch → incomplete. Initial5xx и subresource5xx различены. not_ready проверен без единого upstream-запроса. Cleanup с никогда не завершающимся close() завершил тестовый runner кодом1.
- Controlled Chromium smoke на Mac адаптирует только Linux isolation проверку/Chromium sandbox; не выдавать его за повторный Linux sandbox test. Linux-изоляция и сборка образов были проверены в предыдущем этапе, до этого изменения ожидания запросов; ОС/контейнерная конфигурация в текущей правке не менялась.
