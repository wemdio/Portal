Пользователь уточнил, что специалист смотрит ответ в личном кабинете Mailganer на Portal, а не в Instantly. Ранее сделанная рекомендация по интерфейсу Instantly не решала её задачу.

Причина в Portal: `mapInstantlyEmailToThreadMessage` возвращал только plain `body_text`; HTML-ссылка на приложенное изображение пропадала при преобразовании письма в текст. Для письма с Carrot Quest ссылка на скриншот находилась в `<a href=".../image.png">`, а `<img>` был лишь значком скрепки.

В ветке `Sergey` добавлено извлечение HTTPS-ссылок на поддерживаемые изображения из HTML без передачи сырого HTML клиенту; карточка переписки показывает имя файла и превью по нажатию, плюс ссылку для открытия отдельно. Внешние изображения не загружаются автоматически. Тесты переписки (29) и строгая проверка TypeScript прошли. Прод не изменён; после пуша требуется обычный релиз пользователем.
