Follow-up to 2026-10-20-2418bbaa0a54: user suggested dynamic SMTP proxy switching after refusals. Implemented in the existing authorized dmitriy_kuladmed_new branch, based on 3ca54b831. No push or production changes.

Shared email validator now fails over explicit permanent egress refusals (including recorded Microsoft 550 Spamhaus) only when existing recipient classification is unknown and no success, catch-all confirmation, greylist or quota is present. Recipient echoes are stripped before matching IP-block language. Reuses per-MX/proxy 30-minute block memory and finite once-per-endpoint sequence. All blocked results normalize to inconclusive; definitive recipient rejections, generic policy/5.7.1, quota, and ordinary greylist affinity are preserved. This does not fix suspicious scraped web-subdomain addresses or change the EN breaker threshold.

Verified with 18 offline scenarios against the actual validator, including recorded 550/250 replay, TTL expiry, per-MX isolation, failure exhaustion, recipient rejection after failover, greylist affinity, unchanged transport and 4xx behavior, and unresolved catch-all safety. Related Jest: 23 suites / 280 assertions passed in about 10 seconds. Core TypeScript and ESLint passed. No permanent tests added.
