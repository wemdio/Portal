## Запрос и результат
17 сентября 2026 пользователь показал failed Semaphore deploy main 9669c4a (#2560). Read-only диагностика установила сбой на Step 3 drain workers: `/dev/fd/63: line 218: PRIVATE: command not found`.

Причина: drain-worker.sh выполнял весь Docker .env через shell source. На строке 218 был SENDER_GOOGLE_SA_PRIVATE_KEY с некавыченной PEM-шапкой и пробелами. Проверялись только имя настройки/форма значения; сам ключ не выводился и не копировался.

Исправление: читать только NEXT_PUBLIC_SUPABASE_URL и SUPABASE_SERVICE_ROLE_KEY как данные, не исполняя и не экспортируя остальные настройки. Поддержаны простые кавычки, CRLF/BOM, повторные значения и fallback к окружению. Некорректное кавычкование нужного параметра останавливает скрипт до действий с воркерами и без вывода значения. Compose продолжает сам читать полный .env.

## Проверки
Локальный изолированный прогон полного drain-worker.sh с подменами docker/sudo/curl: PEM, quoted CRLF/BOM/duplicate, буквальная command substitution без исполнения, отсутствие .env, пустое значение поверх окружения, некорректная кавычка. Остановка 12 Base Constructor реплик и запрос передачи задач сохранены. На синтетическом PEM показан прежний PRIVATE command-not-found при source; на этом Mac source через process substitution не читает данные, поэтому сравнение использовало прямой source нормализованного LF-файла. Проверены bash -n и существующие 54 проверки выбора целей деплоя.
