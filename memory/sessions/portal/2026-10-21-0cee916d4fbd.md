Запрос пользователя 21.10.2026: из «КП отправлено» должны быть доступны четыре перехода: «Встреча проведена», «Перенос», «Согласование договора», «Закрыто и не реализовано».

В app/src/lib/amoFunnelGuard/rules.ts добавлено отдельное правило для исходного этапа КП; отказ перечисляет эти направления. Общая цепочка ранее запрещала прямой переход к договору. Тот же checkTransition используется webhook и reconcile. Остальные правила не менялись.

Проверено локально: вызов функции для всех 196 пар известных этапов, сравнение остальных переходов с прежней реализацией, исключения для других воронок, сообщение об отказе; ESLint и TypeScript 7 для изменённого модуля. Постоянные тесты не добавлялись. ID этапов сверены read-only по Portal DB (синхронизация 21.10.2026); старые этапы могут оставаться в справочнике, поэтому не менять всю цепочку по одному sort.

Область: dmitriy_kuladmed_new, исходный HEAD a680f61ff. Production и AMO не изменялись; push/deploy требуют отдельного согласования. На Windows helper памяти запущен через временный адаптер блокировки msvcrt, без изменения репозиторного helper.
