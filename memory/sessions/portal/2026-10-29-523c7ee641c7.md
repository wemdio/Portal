## Запрос и коррекция понимания

29.10.2026 пользователь передал шесть Google Sheets не для сообщения Глебу и не для согласования/запуска. Он уточнил: email-адреса из этих баз нужно поставить в стоп-лист собственного английского автоаутрича. Русский контур и чужие кампании не затрагивать, домены целиком не блокировать. После отдельных запросов прав чтения, явно разрешённых пользователем, все шесть источников доступны.

## Выполнено на production по прямому поручению

Из явных email-колонок всех листов получено 26 603 уникальных нормализованных адреса. Одной транзакцией добавлены исключения для всех 20 текущих кампаний source_kind=polza_en папки auto_en. Записей «кампания — адрес» 532 060 (не число уникальных адресов): 532 059 новых, одна прежняя mailbox_lost переведена в manual; другие прежние причины не затирались.

Совпадений с получателями 536; остановлены 308 активных цепочек, отменены 36 ожидающих писем. Sending на момент операции — 0. Последующая проверка MCP: 0 active, 0 scheduled, 0 записей операции вне EN. Ранее отвечавшие/завершённые получатели и история сохранены. Общий sender_suppressions не менялся.

Проверенный SSH — root@139.60.162.24, DB-контейнер main-postgres. Снимок изменяемых получателей/ожидающих писем: main-postgres:/tmp/en-stoplist-20261029-before.csv, права 0600 проверены. Маркер исключений в note: en-bases-20261029. Полные адреса, выгрузки, SQL и журналы только в .codex-tmp/, не в Git. Снимок не даёт разрешения на откат.

## Будущие EN-кампании — код ещё не выложен

В существующей polza_outreach_settings сохранён ключ blocked_emails с JSON-массивом тех же 26 603 строк. Продовая старая версия ключ не читает. Подготовлен loadEnEmailStopList: один read на запуск/импорт, сбой/повреждение списка запрещают заливку. EN S5 отсекает адреса отдельно, а importRecipients повторяет проверку только для polza_en перед любыми записями/заменой базы. Другие контуры не читают эту настройку. Счётчик skippedSuppressed должен учитывать только пересечение входных адресов со списком, не все 26 603 записи настройки.

Для автозащиты новых EN-кампаний нужна штатная выкладка этой правки. Ни push, ни merge, ни deployment в этой задаче не делались. Текущие 20 кампаний уже защищены независимо от выкладки.

## Проверка и источники

Временный harness .codex-tmp/verify-en-email-stoplist.cjs исполнил реальные loader/importRecipients/S5-цикл: большая база, регистр/повторы, ошибки и битые данные, отсутствие записей до сверки при replace, RU/manual/VE2, общие исключения, точные счётчики. 37 существующих проверок senderHardening и VE2 senderTransport прошли, новых постоянных тестов нет.
