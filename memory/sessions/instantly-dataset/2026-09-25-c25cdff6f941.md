## Bounded implementation

- Recognize a single outer Thunderbird direct-reply citation `blockquote[type=cite][cite=mid:<uuid>@<receiving-mailbox-domain>]` immediately following `.moz-cite-prefix`. Reject nested forwards, arbitrary URLs, missing mailbox/recipient/time, unsupported subjects and oversized HTML.
- An unproven citation may trigger at most one exact provider GET per resolution, only if that ID is absent from prefetched context. No new LIST search or AI call. Reuse existing provider rate limiter; disable eager HTTP retries and bound transport/body consumption to 20 seconds. Preserve error messages for the existing durable retry/backoff machinery. Recovery priority options are propagated; GET continues using the existing non-LIST limiter.
- The hint itself is not ownership evidence. Require the returned actual outbound ID, outbound kind, campaign, sender and sending/receiving account, earlier timestamp, same normalized subject, exactly one actual original recipient and equality of the complete substantive quoted text with the actual send. Different corporate addresses must share the same exact non-free domain; different public-mail users and cross-company recipients are not accepted.
- Resolve the proven send through the existing project ownership links and ambiguity guards. Do not globally relink a reused mailbox. Missing/contradictory source or dependency failure defers instead of guessing.
- Preserve independently verified legacy conversations: an unavailable optional older citation must not block existing proof. Run the citation lookup before old completed identity-only evidence checkpoints so a negative search by the responding colleague cannot hide the original send.
