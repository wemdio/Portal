## Implementation scope

`app/src/lib/instantly/replyOwnershipResolver.ts` adds a fallback only after a complete parent search found no matching outbound, with no outbound in the prefetched conversation. It requires a direct, non-nested, non-forwarded subjectless quote: exact receiving sender, same quoted recipient / actual responder / provider lead, sole receiving mailbox, valid timezone-bearing quote timestamp before the reply and within 24 hours, substantial quoted body. The provider campaign must be absent from the unfiltered mailbox mappings. All current owners must be the same managed project with a manual current anchor and a shared exclusive non-reserve tag; denies, unknown statuses, historical foreign owners, unknown non-draft mappings, self-service owners, mixed sender/tag scopes and metadata errors fail closed. An unlinked draft is not treated as an additional active project. Existing actual-parent proof remains authoritative.

This recovers a project, NOT the exact original campaign/send. The manual anchor is explicitly a representative campaign; `lastOutbound` stays null and `conversationVerified` is not fabricated. Global links, tags, classification rules, client settings and notification implementations are unchanged. Existing changed-recipient quote parsing defaults and ordinary mailbox fallback behavior remain unchanged.
