## Исправления
- Телефоны: исключаются фрагменты timestamp и буквенно-цифровых реестровых ID; поддержан пробел после плюса, явное направление в мессенджер и тел/факс. В прежнем NON_PHONE_LABEL конец слова «факс» ошибочно совпадал с «кс» (корреспондентский счёт).
- Контакты: собственная подпись после полностью размеченной цитаты, HTML source wrapping, имя у телефона/роли, полное юридическое название. Явное сообщение об ушедшем сотруднике позволяет заменить именно совпадающее импортированное имя, не произвольное имя и не ручную запись таблицы. Голый домен из импорта слабее полного названия в подписи.
- Board-only request projection: не теряется содержательный ответ, полностью написанный внутри gmail_signature; исключена шапка «От кого» из старой переписки. Оригинал для квалификации/контактов не изменяется.
- Default qualification: готовность «пообщаться подробнее» плюс только Telegram после пустого opener — не конкретная коммерческая встреча; общий запрос контактов в support ticket — не принятие оффера. Кастомные критерии и реальные коммерческие/назначенные CTA сохранены.
- Пять полных служебных шаблонов из pending cohort распознаются до ownership. Проверяется целый текст; добавленный человеческий запрос отменяет технический shortcut. Хранящийся полный inbound больше не требует повторного provider GET для такого machine verdict.
- Два клиентских post-handoff ответа разрешаются только по локальному журналу SENT, точному sender/mailbox/recipient, цитате полного draft, теме, хронологии и совпадению исторического proven project с текущим владельцем кампании. НЕ по одному thread_id: в двух реальных разных диалогах provider вернул одинаковый thread token.
- Local quota не сбрасывает уже накопленную серию ownership failures; краткий quota wait остаётся <=65 секунд, повторный ownership failure сохраняет экспоненту до 6 часов.
