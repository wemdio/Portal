# Проверка риска: цитата без строки «Тема»

Проверен изолированный прототип относительно Sergey 2fe11b872. Рабочий исходный код, ветка и production не изменены. Никаких реальных вызовов ИИ, отправок, повторной квалификации или новых постоянных тестов.

## Граница исправления
Общий quotedOutbounds() остаётся неизменным. Дополнительный путь допустим только для прямого ответа с другого адреса: один блок From/To/Date без Subject, один исходный адресат, наш точный ящик среди получателей ответа, явная дата с часовым поясом, совпадение минуты отправки, нормализованной темы самого ответа и полного существенного текста реального исходящего. Прототип поддерживает только наблюдённый русский формат даты. Пересылки, вложенные цитаты, явный противоречащий Subject, CC внутри цитаты не проходят дополнительный путь.

## Проверенные результаты
- 506 существующих тестов / 18 suites прошли с экспериментальной подстановкой resolver в памяти, включая worker, Others, custom policies, handoff, isolation routes, board.
- Core TypeScript проверен через виртуальную подстановку исходника, без изменения файлов приложения.
- 28 отрицательных вариантов входящего и 13 отрицательных вариантов исходящего не дают нового ошибочного назначения Smartway.
- 6 сценариев: недоступный API/БД, незавершённая пагинация, конкурирующий другой проект, неизвестный проект, две привязки одной кампании — не дают автоматического назначения.
- 24 варианта пробелов/переносов/приветствия, HTML-only и 60 секунд в пределах указанной минуты распознаются.
- 48 сохранённых квалифицированных ответов не активируют новый путь; результаты существующего строгого парсера цитат совпали до/после.
- Реальный кейс: baseline ambiguous, prototype Smartway. Неизменённый текст ответа и реальный оригинал передаются в контекст квалификации.
- В локальном API-моке поиск этого кейса требует 4 чтения вместо 2, либо 0 дополнительных чтений при уже полученном оригинале. Дополнительных AI-запросов нет.

## Ограничения
Это не доказательство отсутствия любых будущих ошибок. Не прогонялась вся историческая почта с полными историями отправок, не вызывалась живая модель. 48 ответов — проверка области срабатывания и парсера, не повторная оценка точности ИИ. Production rollout не выполнен и не разрешён этой проверкой. Существующие критерии lead/not_lead и кастомные критерии не менялись. Переход к реализации требует сохранить именно узкие условия и повторить проверки.
