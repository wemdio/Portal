# Handoff adaptation: repeated commitments and signature protection

Implemented on Sergey after the September 22 diagnostic: adaptation now replaces an existing acknowledgement/return promise instead of adding a second one. The prompt explicitly permits that limited replacement, forbids duplicate meaning, and preserves paragraphs and any existing signature.

buildHandoffDraft keeps recognised Russian/English sign-offs and all following signature text outside the model, then appends the exact approved suffix (including line breaks and typography). Added return commitments beyond the template's existing budget and newly repeated identical sentences reject the optional adaptation in favour of the approved legend; no sentence is silently deleted. This is a bounded lexical guard, not proof that arbitrary semantic paraphrases cannot repeat. Unrecognised signature formats remain model-visible.

Validation: 12 offline mocked-provider scenarios covering the observed duplicate, plural/English variants, identical sentences, valid contextual replacement, invented signature, CRLF signature preservation, empty/wrong-language output, AI OFF, missing key and pre-approved distinct commitments. Existing handoff/ownership suites: 29 passed; ESLint, TypeScript and diff checks passed. No paid AI calls, production writes, email/Telegram sends or historical draft changes.
