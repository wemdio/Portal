# Уточнение пользователя: КП при неполной истории

- Пользователь различает ответ на известное первое письмо без раскрытого оффера (общее «пришлите КП» не подтверждает квалифицированный интерес) и запрос КП с другого адреса, где человек мог получить предложение через коллегу.
- Не найденный оффер != доказанное отсутствие оффера. Другой адрес/сотрудник сам по себе не отрицательный признак. Оффер можно подтверждать достоверно связанной пересылкой/историей; новый автор не обязан повторять текст оффера.
- Сам запрос КП — сигнал, но не доказательство ознакомления. Пользователь говорит «наверное/скорее всего», а не утверждает автоматическое «все КП — лид».
- В docs/integrations/instantly-weekly-evaluation-20260919.md уточнён candidate weekly-policy-v2: известный оффер / известное пустое знакомство / неизвестный контекст. Это внутренние признаки, финальная операция остаётся бинарной.
- Граница generic КП + полностью невосстановленная история ещё открыта; не назначать ей gold-метку от имени пользователя. Не вводить ручную очередь или безграничный поиск контекста.
- Меняются только описание тестовой политики и память; production classifier, модели, данные и ранее замороженная выборка не изменены. Предыдущая запись: sessions/instantly-dataset/2026-09-19-7af9766e0dd2.md.
