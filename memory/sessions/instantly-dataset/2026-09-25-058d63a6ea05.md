## Scope
Implemented the previously isolated narrow subjectless-quote recovery after user asked to proceed. Branch Sergey, base 9ea811c13 (two unrelated VE2 commits fast-forwarded before edits). Only application source change is app/src/lib/instantly/replyOwnershipResolver.ts. Prior diagnostic and prototype records: 2026-09-25-444ed6063e94 and 2026-09-25-f8369ec002c2.

## Implementation
- Existing quotedOutbounds and classification rules remain unchanged.
- Separate direct changed-address hint requires one From/To/Date block without Subject/CC, a single different original recipient, exact receiving mailbox, explicit Russian timezone-bearing date, direct Re/Ответ subject, no forwarded/nested headers. Own-sender replies and invalid calendar dates are excluded.
- Ownership still requires the real outbound: exact sending mailbox and recipient, same normalized reply subject, entire substantial quoted body, matching sent minute and chronological order. Conflicting/unknown owners keep existing fail-closed behavior.
- Original recipient only expands the bounded evidence search. New evidence version 4 applies only to this narrow format, invalidating its old missing-recipient checkpoint; all other shapes retain version 3. No new retry loop or global backfill.
- In the saved case, fresh and recovery paths resolve the actual Smartway send; reply body is preserved and original outbound becomes qualifier context. No model or criteria changes.
