## Запрос и результат

Добавлена перестановка колонок гостевой таблицы `/leads-board/[token]`: drag-handle в заголовке, Alt+стрелки и кнопки в меню «Колонки» для телефона/клавиатуры. Порядок сохраняется для всей доски проекта, а не отдельно для посетителя. Это изменение кода; production и миграции не запускались.

## Важные детали

- Ранее `normalizeColumnConfig` принудительно возвращал builtin-колонки к дефолтному порядку, а custom ставил в конец. Теперь сохраняет смешанный порядок, дополняя отсутствующие builtin; некорректные/повторяющиеся ключи и полностью скрытый набор запрещены.
- Перестановка отправляет только `columnOrder` (все стабильные ключи). Сервер берет метаданные из актуального конфига, требует тот же набор ключей и обновляет только `project_lead_boards.column_config/updated_at`; значения `project_lead_board_rows` не затрагиваются. Guest capability-проверка сохранена. UPDATE дополнительно ограничен token и прочитанным updated_at для защиты от изменений во время запроса.
- Сохраняется один конфиг за раз, ошибка откатывает только порядок/конфиг, не перечитывая и не затирая параллельно отредактированные строки. Старый ответ GET не перезаписывает новый порядок. Полные конфиги старых клиентов совместимы, но глобальной блокировки всех открытых вкладок нет.
- Заголовки, редакторы ячеек и TSV используют одинаковые стабильные ключи. Автоматическое заполнение, воркер и Telegram не изменены. Миграция не нужна: порядок уже хранится JSONB-массивом.
